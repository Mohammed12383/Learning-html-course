Arrays & Vectors

One variable holds one value. To keep a whole list (the scores of every player, the cards in a hand) you need many boxes in a row. C++ has two ways: the classic array, and the friendlier vector.

  • Arrays
  • Vectors

Boxes side by side

An array is a row of boxes of the same type, right next to each other in memory. Each box has an index (position), starting at 0:

scores =
72[0]
95[1]
88[2]
64[3]
91[4]

A classic array has a fixed size: int scores[5] always has exactly 5 boxes. You can't add a sixth. That's why most C++ programmers use vectors instead.

Vectors: arrays that grow

A vector is a list that can grow and shrink, and knows its own size. Add #include <vector>, and put the item type in angle brackets: vector<int> is "a vector of ints".

for (string name : friends) is the range-for loop: it visits each item in turn. It's the easiest way to go through a vector.

Stay inside the boxes!

This is important in C++. With v[i], C++ does not check that i is inside the vector. If it isn't, the program reads random memory, gives nonsense, or crashes. v.at(i) checks, and stops the program with a clear error instead:

The program stops with an "out of range" error. A vector of 3 items has indexes 0, 1 and 2. While you're learning, .at() is the safer choice.

Remember

  • Arrays: int a[5] = {...}; fixed size.
  • Vectors: #include <vector>, vector<int> v;, push_back, pop_back, size().
  • for (int x : v) visits every item.
  • Indexes go from 0 to size − 1. .at(i) checks the index for you.
