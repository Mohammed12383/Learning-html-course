Math

C++ is lightning fast at math: billions of calculations per second. That's why games and science use it. But C++ math has one famous surprise that catches every beginner. This lesson shows you how to avoid it.

The operators

OperatorDoesExampleAnswer
+add7 + 29
-subtract7 - 25
*multiply7 * 214
/divide7 / 23 (!) and 7.0 / 2 is 3.5
%remainder (only for whole numbers)7 % 21

Brackets first, then * / %, then + -. So 2 + 3 * 4 is 14 and (2 + 3) * 4 is 20.

The integer division surprise

When you divide an int by an int, C++ gives an int answer, and throws away the decimals:

If at least one side is a double, the answer is a double. To divide two int variables properly, turn one into a double with static_cast<double>(x). This is called a cast.

When integer division is useful

Sharing 17 cookies among 5 friends: 17 / 5 is 3 cookies each, and 17 % 5 is 2 left over. And n % 2 == 0 tells you a number is even.

Boxes have limits

An int is 4 bytes, so it can only hold numbers up to about 2.1 billion. Go past that, and the number "wraps around" to a big negative number. This is called overflow. For bigger numbers, use long long (8 bytes, up to about 9 quintillion):

Common mistakes

  • Integer division by accident: 1 / 2 is 0. Write 1.0 / 2.
  • Using ^ for power: in C++ ^ means something else entirely. Use pow(a, b).
  • % with decimals: 7.5 % 2 doesn't compile. % is only for whole numbers.
  • Dividing by zero: with ints, the program crashes.

What does cout << 9 / 2; print?

Both are ints, so it's integer division: the .5 is thrown away.

Remember

  • int / int gives an int. Use a double (7.0 or static_cast<double>(x)) for decimals.
  • % is the remainder. x += 5, x++, x--.
  • #include <cmath> for sqrt, pow, round, floor, ceil.
  • long long for very big whole numbers.
