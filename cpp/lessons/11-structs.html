Structs

A game character has a name, health and a position. Keeping those in separate variables gets messy fast. A struct lets you make your own type that bundles related values together under one name.

Your own type

A struct describes a new type. Each value inside is called a field (or member):

zaraname: "Zara" health: 75 level: 2a Hero
leoname: "Leo" health: 80 level: 3a Hero

Each Hero has its own copy of every field. A struct's fields sit next to each other in memory, like one bigger box with compartments.

Common mistakes

  • Forgetting the semicolon after the struct's closing }. The error message can be confusing!
  • Values in the wrong order: {"Zara", 100, 1} fills the fields in the order they're written in the struct.
  • Changing a copy: void grow(Rect r) grows a copy. Use Rect& r.

struct P { int x; int y; }; P a = {2, 5}; What is a.y?

The values fill the fields in order: x gets 2, y gets 5.

Remember

  • struct Name { type field; ... }; makes a new type. Don't forget the ;.
  • Name v = {a, b}; makes one. v.field reads or changes a field.
  • vector<Name> makes a table of them.
  • Pass to functions by const Name& (read) or Name& (change).
