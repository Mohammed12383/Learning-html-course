Input with cin

cout sends things out to the screen. cin brings things in from the keyboard. With input, your programs can ask questions and react to the answers.

  • cin and >>
  • Reading several values
  • getline for whole lines
  • Checking the input

cin: read from the keyboard

cin (say "see-in") is the keyboard. The arrows >> point the other way from cout: the value flows from cin into your variable.

How input works in this course

On a real computer, the program pauses and waits for you to type. Here, the code is sent to an online compiler all at once, so you type your answers before pressing Run, in the Input box above the output. Put each answer on its own line.

Change the number in the Input box and press Run. Because age is an int, cin reads a whole number from the input, and you can do math with it right away. (The cout << endl; just starts a new line, since the input you typed isn't shown in the output here.)

Checking the input

What if someone types "hello" when you asked for a number? cin fails, and the variable gets 0. You can check: if (cin >> x) is true only when reading worked. (You'll learn if properly in the next lesson.)

Input is "Sam Rivers". string s; cin >> s; What is in s?

>> stops at the first space. Use getline(cin, s) to read the whole line.

Remember

  • cin >> x; reads a value into x. Chain them: cin >> a >> b;
  • >> reads one word or number. getline(cin, s) reads a whole line.
  • Use cin >> ws; before getline if you used >> before.
  • if (cin >> x) checks that reading worked.
