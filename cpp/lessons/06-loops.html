Common mistakes

  • Commas instead of semicolons inside for ( ; ; ).
  • Off by one: i < 10 stops at 9. Use i <= 10 to include 10.
  • A semicolon after the for: for (...); repeats nothing, then runs the block once.
  • Forgetting to change the variable in a while loop.

How many stars? for (int a = 0; a < 3; a++) for (int b = 0; b < 4; b++) cout << '*';

The inner loop prints 4, and the outer loop runs it 3 times: 3 × 4 = 12.

Remember

  • for (int i = 0; i < n; i++) { }: start, keep going while, after each round.
  • while (q) { }. do { } while (q); runs at least once.
  • break leaves the loop, continue skips to the next round.
  • Nested loops make rows and columns. setw(n) lines them up.
