= vs ==

= stores a value. == compares two values. Writing if (x = 5) by mistake stores 5 in x and is always true: a classic C++ bug. The compiler often warns you about it.

  • && and: both must be true.
  • || or: at least one must be true.

Common mistakes

  • = instead of == in a question.
  • A semicolon after the if: if (x > 5); ends the if right there, so the block always runs.
  • Forgetting break in a switch.
  • Writing 0 < x < 10: that doesn't work like in math. Write x > 0 && x < 10.

Which one checks if x is between 1 and 10?

Both conditions must be true, so use &&. With ||, every number would pass.

  • && and, || or, ! not.
  • switch (x) { case 1: ... break; default: ... }
