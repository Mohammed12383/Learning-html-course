Strings

A string is text: names, messages, passwords. Under the hood it's a row of char boxes, a bit like a vector of characters. In this lesson you'll join, search, cut and change text.

When find can't find something, it gives a special value called string::npos ("no position"). Always check for it, as the code above does.

Text and numbers

You can't add a number to a string with + directly. Turn it into text first with to_string. Strings can be compared with ==, < and >, in dictionary order.

Common mistakes

  • Single vs double quotes: 'a' is a char, "a" is a string.
  • Adding numbers to strings: "Age: " + 12 doesn't do what you think. Use to_string(12).
  • substr's second number is how many characters, not where to stop.
  • Forgetting to check string::npos after find.

string s = "pancake"; What is s.substr(3, 4)?

Start at index 3 (the 'c') and take 4 characters: c, a, k, e.

Remember

  • #include <string>. Join with + and +=.
  • s.length(), s[i], s.substr(start, count), s.find(x).
  • for (char c : s) visits each character. toupper/tolower from <cctype>.
  • to_string(n) number → text. stoi(s), stod(s) text → number.
