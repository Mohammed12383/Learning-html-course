cout: print things

cout (say "see-out", for "character output") is the screen. The arrows << push things onto it, like pouring water into a cup:

You can chain as many << as you like. Text in quotes is printed exactly. Numbers and math without quotes are calculated: 5 + 3 prints 8. Notice that cout doesn't add spaces for you: put them inside the quotes.

New lines: endl and \n

Without endl, everything stays on one line. There are two ways to start a new line:

\n inside text means "new line". endl does the same and is easier to read. Use whichever you like.

Comments

Comments are notes for people. The compiler ignores them. // lasts until the end of the line. /* ... */ can cover several lines.

Reading compile errors

C++ is strict about every little detail: every instruction ends with ;, every { needs a }, every " needs a partner, and capital letters matter. When something's off, the compiler gives you:

  1. the line number (marked in red in the code),
  2. an error message written for programmers,
  3. and in this course, a plain explanation of what it means.

Press Run, fix the first error, Run again. Repeat until it works.

Tip: the error is often one line earlier

A missing ; is reported on the next line, because that's where the compiler notices something's wrong. Always check the line before too.

Common mistakes

  • Missing semicolon at the end of an instruction.
  • Capital letters: Cout, Main and Endl don't exist.
  • Arrows the wrong way: printing uses << (toward cout).
  • Curly quotes “like these” from a word processor or the iPad keyboard. Code needs straight quotes ". On an iPad, turn off Smart Punctuation in Settings → General → Keyboard.

Where does every C++ program start running?

The computer always starts at int main().

Remember

  • The frame: #include <iostream>, using namespace std;, int main() { ... return 0; }.
  • cout << "text" << value << endl; prints.
  • \n new line, \t tab, \" quote, \\ backslash.
  • Every instruction ends with ;. Check the line before an error too.
