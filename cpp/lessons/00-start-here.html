Why C++?

C++ is one of the most powerful programming languages in the world. It's used when programs need to be very fast or need to control the computer closely:

games

Big game engines like Unreal Engine are written in C++.

browsers

Chrome, Firefox and Safari are mostly C++.

robots

Robots, cars, drones and Mars rovers run C++.

apps

Photoshop, music software, and parts of Windows and macOS.

C++ asks you to be more careful and precise than Python or TypeScript. In return, you learn how computers really work inside: memory, addresses and types. That knowledge makes you better at every language.

What a compiler does

Computers don't understand C++ directly. They only understand machine code: millions of tiny instructions made of 1s and 0s. A program called a compiler translates your C++ into machine code. Then the computer runs that machine code, very fast.

your code main.cpp
the compiler checks and translates it
mistakes found
compile errors, with line numbers. Nothing runs.
no mistakes
a program in machine code, which runs

So there are two moments: compiling (checking and translating) and running. If the compiler finds a mistake, nothing runs at all. It tells you the line and what's wrong, and you fix it.

How to use this course

  • Run sends your code to a real C++ compiler online (a free service called Compiler Explorer), runs it, and shows the output. It takes about a second, and it needs an internet connection.
  • Before you press Run, each box shows the saved result: what the example prints. You can read every lesson offline, but running changed code needs internet.
  • Programs that read input have an Input box: type the answers before pressing Run, one per line.
  • Compile errors mark the line in red, with a plain explanation.
  • Reset brings the code back. Copy copies it.
  • Step-through viewers show a program running one line at a time, with pictures of memory.

Code is colored to help you read it, the same way everywhere:

C++ on your own computer

  1. Online, no install: godbolt.org (Compiler Explorer, the same compiler this course uses) and other online C++ editors work in any browser.

  2. On a Mac: open the Terminal app and type xcode-select --install. That installs a C++ compiler called clang++.

  3. On Windows: install Visual Studio Community (free) and choose "Desktop development with C++".

  4. Write your code in a file ending in .cpp, then compile and run it. Lesson 15 shows exactly how.

What does a compiler do?

The compiler translates the whole program into machine code before anything runs. If it finds mistakes, it stops and tells you.
