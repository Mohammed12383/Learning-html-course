Functions

You've been using one function all along: main. Now you'll write your own. A function is a named piece of code you can use again and again. You'll also learn one of C++'s most important ideas: the difference between passing a copy and passing the real thing.

A copy, or the real thing?

This is a big idea in C++. Normally, a function gets a copy of the value. Changing the copy doesn't change the original. This is called pass by value.

Put & after the type, and the function gets a reference: another name for the same box. Changing it changes the original. This is called pass by reference.

Common mistakes

  • Using a function before it's written: put functions above main (or declare them first, see lesson 15).
  • Forgetting return in a function that isn't void.
  • Expecting a copy to change the original: add & if the function must change it.

void addOne(int x) { x++; } What happens to n after addOne(n)?

x is a copy. To change n, the parameter would need to be int& x.

Remember

  • returnType name(type param) { ... return value; }. void returns nothing.
  • Write functions above main.
  • int n gets a copy. int& n gets the real box. const string& s reads without copying.
  • Default values: int times = 3. Overloading: same name, different parameter types.
