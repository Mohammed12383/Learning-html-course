Learn C++, the language of games

C++ is fast and powerful: it runs video games, web browsers, robots and space probes. Every lesson shows a short explanation, the code, and what it does, side by side, with pictures of what happens inside the computer's memory. No experience needed.

How every lesson works

You learn by looking and trying. Each idea comes with a small program you can change and run.

1 · read

A short, simple explanation

Plain words and pictures. Every new word is explained the first time you meet it.

2 · run

Code and result side by side

Press Run to compile and run your code with a real C++ compiler. Step-through viewers show memory changing one line at a time.

3 · try

Change it, break it, fix it

Compile errors are marked on the right line and explained in plain English. Reset always brings the code back.

The course

17 lessons, in order. Each one takes about 15 to 30 minutes. Your progress is saved in this browser. Learning Python or TypeScript first makes C++ easier, but you don't have to.
