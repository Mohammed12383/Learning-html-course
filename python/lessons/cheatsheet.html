Errors

ErrorUsually meansFix
SyntaxErrorMissing bracket, quote or colonCheck this line and the one before
IndentationErrorSpaces at the start of a line are wrongPush in by 4 spaces, line up blocks
NameErrorUnknown name (typo, or not created yet)Check spelling and order
TypeErrorMixing types, like text + numberUse str() or int()
ValueErrorRight type, wrong value, like int("hi")Check the input, use try/except
