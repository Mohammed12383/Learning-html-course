Final Project: Pocket Pet

Time to put it all together. You'll build Pocket Pet: a little game where you hatch a pet, then feed it, play with it and put it to bed for 10 days. It uses variables, input, if, loops, lists, dictionaries, functions, a class and random. Every part of it is something you've learned.

Play the finished game first

Press Run and play. Type your answers in the output box. Can you keep your pet happy for 10 days?

Step 1: plan before you code

Before writing any code, programmers write a short plan in plain words:

  1. The pet has a name, a kind (an emoji), and three numbers from 0 to 10: hunger, happiness, energy.

  2. Each day: show the pet, ask the player what to do (feed, play, sleep), then make a day pass.

  3. Each day, the pet gets hungrier and a bit less happy. Sometimes a random surprise happens.

  4. The game ends after 10 days (you win), if the pet is starving or sad (you lose), or if the player quits.

Notice how the plan already shows which tools you need: a class for the pet, a while loop for the days, if/elif for choices, random for surprises.

Step 2: the data

From lessons 2, 10 and 11.

The foods are a dictionary. Each value is a pair of numbers in brackets (3, 0), called a tuple: like a small list that can't change. clamp() is a tiny function that keeps every number between 0 and 10, so hunger can never be −2 or 15. bar() turns a number into a little bar, like ███···.

The text in triple quotes right under def is called a docstring: a comment that explains what the function does.

Step 3: the Pet class

From lesson 13.

__init__ sets the starting numbers. Then each thing the pet can do is a method: feed, play, sleep, next_day. Each method changes the pet's numbers with clamp() and prints what happened. face() uses if to pick an emoji that shows the pet's mood, and is_ok() answers True or False: is the pet still OK?

Look at feed(): if the food isn't in the dictionary, it prints a message and uses return to leave the method early. That's a neat trick for handling bad input.

Make it yours

Ideas to remix Pocket Pet

  1. New food: add "pizza": (5, 2) to FOODS. It appears in the game automatically!
  2. New action: add a bath() method and a (b)ath choice that makes the pet happier.
  3. New surprises: add more random events to the list in next_day().
  4. Harder game: make the pet get hungrier faster, or play for 20 days.
  5. A score: at the end, give points for happiness and print a rating with stars ⭐.
  6. Two pets: make a list of two Pet objects and take care of both!

What to learn next

  1. Build small things often. The best practice is making your own little programs: a homework helper, a game, a joke generator.

  2. Python on a computer. Install Python (see lesson 0) to use files, packages like pygame for real games, and much more.

  3. Read and practice. The free online book Automate the Boring Stuff with Python and the official tutorial at docs.python.org are great next steps.

  4. Learn more languages. The Hello courses also teach HTML (websites), TypeScript (interactive websites) and C++ (fast programs and games). Now that you know Python, they'll feel familiar.

In Pocket Pet, why does the code use continue when the player types an unknown letter?

continue jumps straight back to the top of the loop, skipping the rest, including pet.next_day().
