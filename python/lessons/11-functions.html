Functions

You've been using functions since lesson 1: print(), len(), input(). Now you'll make your own. A function is a mini-program with a name. Write it once, use it as many times as you like.

Writing def greet(name): only teaches Python the function. Nothing happens until you call it: greet("Lina"). Then "Lina" goes into the parameter name, and the function's lines run.

return: giving an answer back

return sends a value back out of the function, so you can store it or use it. This is different from print, which only shows something on the screen:

print shows, return gives

A function that only prints is like a friend who tells you the answer out loud but won't write it down. A function that returns hands you the answer on paper, so you can use it again. Most functions should return.

Several parameters and default values

  • topping="cheese" is a default value: used when you don't give one.
  • You can name the values when you call: slices=6. Then the order doesn't matter.

Variables inside a function stay inside

A variable made inside a function only exists while the function runs. Outside, it's gone. This is called scope, and it's a good thing: functions can't accidentally mess up each other's variables.

The last line gives a NameError: outside the function, secret doesn't exist. If you need a value outside, return it.

Why functions matter

  • No copying: write the code once, use it everywhere.
  • Easy to fix: fix a bug in one place, and it's fixed everywhere.
  • Easy to read: draw_star(...) explains itself.
  • Building blocks: big programs are made of many small functions.

Common mistakes

  • Defining but never calling the function. Nothing happens until you call it.
  • Calling before defining: Python reads top to bottom, so def must come first.
  • Forgetting return: then the function gives back None.
  • Wrong number of values: area(4) when it needs two gives a TypeError.

def add(a, b): return a + b. What is add(2, 3) * 2?

add(2, 3) returns 5, then 5 × 2 = 10.

Remember

  • def name(param): then pushed-in lines. Call it with name(value).
  • return value gives an answer back. print only shows it.
  • Default values: def f(x, y=10):. Named values: f(1, y=5).
  • Variables inside a function only exist inside it.
