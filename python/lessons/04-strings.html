Text (Strings)

Joining text together

Text and numbers don't mix with +

Python won't glue a number onto text, because it isn't sure what you mean. Fix it by turning the number into text with str(age). Or, much easier, use an f-string.

f-strings: the easy way

Put an f before the quotes, and you can drop any variable or calculation into the text using curly brackets { }. This is the way most Python programmers build sentences.

f"fill in the
blanks"
"Hi normal text
{name}a blank, filled with

The last line shows a bonus trick: {price:.2f} means "show this number with exactly 2 decimals". Perfect for money.

Every letter has a position

A string is a row of characters (letters, spaces, symbols), and each one has a number called its index. Computers start counting at 0, not 1:

P0-6
Y1-5
T2-4
H3-3
O4-2
N5-1

Square brackets get one letter: word[0] is the first, word[-1] is the last (negative numbers count from the end). len(word) tells you how many characters there are.

Slicing: cutting out a piece

word[start:end] cuts out a piece. It starts at start and stops just before end. Move the sliders:

Leave out a number to go from the very start (word[:3]) or to the very end (word[5:]). And word[::-1] is a famous trick that flips the text backwards.

Text methods

Strings come with built-in tools called methods. You use them with a dot: text.upper(). They give you a new string and leave the original alone.

MethodDoes
.upper() / .lower()Capital letters / small letters
.title() / .capitalize()Capitalize Every Word / only the first letter
.strip()Remove spaces at the start and end
.replace(a, b)Swap every a for b
.count(x)How many times x appears
.find(x)The index where x starts (−1 if not found)
.startswith(x) / .endswith(x)True or False
.split()Break text into a list of words (lesson 9)

The keyword in checks if one piece of text is inside another and gives True or False.

Common mistakes

  • Forgetting the f: "Hi {name}" prints the curly brackets literally.
  • Counting from 1: the first letter is [0], not [1].
  • Index too big: "cat"[3] gives an IndexError. "cat" has positions 0, 1 and 2.
  • Forgetting the brackets on methods: text.upper without () doesn't run it.

Remember

  • + joins text, * repeats it. Use str() to turn numbers into text.
  • f"Hi {name}" drops values into text. {x:.2f} shows 2 decimals.
  • text[0] first, text[-1] last, text[2:5] a slice, len(text) the length.
  • Methods: .upper(), .lower(), .strip(), .replace(), .split().
