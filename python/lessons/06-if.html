Making Decisions

Smart programs do different things in different situations. "If it's raining, take an umbrella. Otherwise, wear sunglasses." In Python, that's if and else.

Questions with True or False answers

To make a decision, a program asks a yes-or-no question. In Python, these questions use comparison operators, and the answer is always True or False:

OperatorMeansExampleAnswer
==is equal to5 == 5True
!=is not equal to5 != 3True
>is greater than5 > 8False
<is less than5 < 8True
>=greater than or equal to5 >= 5True
<=less than or equal to4 <= 3False

= vs ==

One equals sign = stores a value. Two equals signs == compares two values. Mixing them up is the most common mistake in programming.

Indentation matters

The spaces at the start of a line are called indentation. In Python they're not just for looks: they tell Python which lines belong to the if. Use 4 spaces. In these code boxes, the Tab key adds 4 spaces, and pressing Enter after a colon pushes the next line in for you.

else: otherwise

else runs when the question is False. Exactly one of the two blocks runs, never both:

elif: more than two choices

elif means "else, if". Python checks each question from top to bottom and runs the first one that's true. Then it skips the rest.

Order matters! If you checked score >= 50 first, a score of 95 would get a C, because that question is true too and it would be found first.

and, or, not

Combine questions with three keywords:

  • and: both must be true. "Is it sunny and warm?"
  • or: at least one must be true. "Is it Saturday or Sunday?"
  • not: flips True and False.

Common mistakes

  • Forgetting the colon : at the end of if, elif and else lines. That's a SyntaxError.
  • Wrong indentation: lines inside the block must be pushed in, and line up with each other.
  • Using = instead of == in a question.
  • Comparing a number to text: input() gives text, so answer == 8 is always False. Compare with "8" or convert with int().

x = 7. Which block runs? if x > 10 … elif x > 5 … else …

7 > 10 is False, 7 > 5 is True, so the elif runs. Only one block ever runs.
