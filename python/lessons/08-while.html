Loops with while

A for loop repeats a set number of times. A while loop keeps going as long as something is true, like "keep asking until they guess the number". In this lesson you'll build your first real game.

Repeat while it's true

while checks a question. If it's True, it runs the pushed-in lines, then goes back to the top and checks again. As soon as the question is False, the loop ends.

for or while?

for

When you know how many times: 10 times, once per letter, once per item in a list.

while

When you don't know how many times: until they guess right, until the game is over, while there's fuel left.

Here we don't know in advance how many days it takes, so while is the right choice.

Common mistakes

  • Forgetting to change the variable inside the loop, so it never ends.
  • Changing it the wrong way: fuel = fuel + 1 when it should go down.
  • Forgetting break in a while True: loop.
  • The loop never starts because the question is already false at the beginning.

How many times does this print? n = 10, then while n > 7: print(n); n -= 1

It prints for n = 10, 9 and 8. When n is 7, 7 > 7 is False and the loop ends.

What does break do?

break leaves the loop. continue skips to the next round.

Remember

  • while question: repeats as long as the question is True.
  • Something inside must change, or it never ends. Use Stop (or Ctrl+C) to stop it.
  • while True: + break for "keep going until…".
  • continue skips to the next round.
