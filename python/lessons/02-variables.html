Variables

Programs need to remember things: your name, a score, how many lives are left. A variable is a box with a name on it, where the computer keeps one thing for you.

  • Making variables
  • Changing them
  • Types: text, numbers, True/False
  • Good names

A box with a label

Imagine the computer's memory is a wall of boxes. When you make a variable, you take a box, write a name on it, and put a value inside.

name"Sam"text
age12number
likes_pizzaTruetrue/false

In Python, you make a variable with an equals sign:

namethe label
on the box
= "store this in"
"Sam"the value
inside the box

= doesn't mean "equals" here

In math, = means two things are the same. In Python, = means "put the value on the right into the box on the left". Read name = "Sam" as "name gets Sam".

When you print(name), Python looks inside the box called name and prints what it finds. Notice there are no quotes around name in the print. With quotes, print("name") would print the word "name" itself.

Changing what's in the box

A variable can change. That's why it's called a variable. When you store a new value, the old one is thrown away. Watch the box called score:

Line 4 is very common in programs: score = score + 5 means "take what's in score, add 5, and put the result back in score". There's even a shortcut for it: score += 5.

Naming your variables

You choose the names. Python has a few rules, and good programmers follow a few habits:

NameOK?Why
scoreYesShort and clear.
player_nameYesUse underscores _ instead of spaces. This style is called snake_case.
level2YesNumbers are fine, but not at the start.
2levelNoCan't start with a number.
player nameNoNo spaces allowed.
xAllowedBut x doesn't say what's inside. Use a name that explains itself.

Names are case-sensitive: Score and score are two different boxes.

Common mistakes

  • Using a variable before making it: print(score) before score = 0 gives a NameError. Remember, Python reads top to bottom.
  • Quotes around the name: print("score") prints the word, not the value.
  • Spelling: scor and score are different variables.
  • Writing it backwards: 5 = x is an error. The box always goes on the left.

After these lines, what is in x? x = 4, then x = x * 2

Python works out the right side first (4 × 2 = 8), then stores the result back in x.

What type is "3.5" (with quotes)?

Anything in quotes is text (a string), even if it looks like a number.

Remember

  • name = value stores a value in a variable. Read it as "name gets value".
  • Storing a new value replaces the old one. score += 5 adds 5.
  • Types: str text, int whole numbers, float decimals, bool True/False.
  • Names: lowercase, underscores, no spaces, can't start with a number.
