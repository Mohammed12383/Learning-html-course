Dictionaries

In a real dictionary, you look up a word and find its meaning. A Python dictionary works the same way: you look up a key and get its value. Phone books, game settings, prices in a shop: they're all dictionaries.

Look things up by name

With a list, you find things by position: items[2]. With a dictionary, you find things by a name you choose, called a key. Think of a wall of labeled drawers:

"apple"0.5key → value
"banana"0.25key → value
"mango"1.2key → value

Pick a key

Choose "pizza": it isn't a key in the dictionary. That's why we check with in first. Asking for a missing key directly, like spanish["pizza"], gives a KeyError.

Adding, changing and removing

Keys are unique: a dictionary can't have the same key twice. Storing to an existing key replaces the old value.

Common mistakes

  • KeyError: asking for a key that isn't there. Check with in, or use .get().
  • Wrong brackets: create with curly { }, but look up with square d["key"].
  • Spelling and capitals: "Apple" and "apple" are different keys.
  • Missing commas between items, or = instead of :.

d = {"a": 1, "b": 2}. What does d["b"] give?

You look up the key "b" and get its value, 2.

Remember

  • d = {"key": value}. Look up with d["key"], or safely with d.get("key", default).
  • d["new"] = x adds or changes. del d["key"] removes.
  • for k, v in d.items(): loops over keys and values.
  • Great for counting, settings, and lookups. Lists of dictionaries make tables.
