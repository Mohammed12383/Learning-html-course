Modules: random, math & more

You don't have to build everything yourself. Python comes with hundreds of ready-made toolboxes called modules: random numbers, math, time, and much more. Programmers around the world share many thousands more.

import: open a toolbox

A module is a file full of useful functions. import loads it, and then you use its tools with a dot: module.tool().

random: dice, coins and surprises

Games need surprises. The random module gives you random numbers and random choices:

CodeGives
random.randint(1, 6)A whole number from 1 to 6 (both included). A dice roll!
random.choice(items)One random item from a list
random.shuffle(items)Mixes the list up (like shuffling cards)
random.random()A decimal between 0 and 1
random.sample(items, 3)3 different random items

Is the dice fair?

Roll a dice thousands of times and count each number. If it's fair, every number should come up about the same amount. Move the slider:

With only a few rolls, the bars are very uneven. With thousands, they get closer and closer. Scientists use exactly this kind of program to test ideas: it's called a simulation.

Your own modules

On your computer, any .py file can be a module. Put useful functions in helpers.py, and in another file in the same folder write import helpers. Then use helpers.greet("Sam"). Big programs are split into many modules this way.

The world of Python packages

Beyond the built-in modules, there are more than half a million free packages made by other programmers. On your computer, you install them with a tool called pip by typing pip install name in the terminal. A few famous ones:

PackageFor
pygameMaking 2D games with graphics and sound
requestsGetting information from websites
flaskBuilding your own websites with Python
pandas and matplotlibWorking with data and making charts

Remember

  • import module, then module.tool(). Or from module import tool.
  • random: randint, choice, shuffle, sample.
  • math: sqrt, pi, floor, ceil. time: sleep.
  • Any .py file can be a module. pip install gets packages on a computer.
