input()

Asking Questions

So far, your programs did the same thing every time. With input(), a program can ask a question, wait for the person to type an answer, and use it. That's when programs start to feel alive.

input() asks and waits

input() shows a question, then pauses the program until the person types an answer and presses Enter. The answer comes back, so you can store it in a variable:

A box appears in the output where you can type. Press Enter (or the Enter button) to answer. Run it again and give different answers: the program does something different each time.

Tip

End your question with a space, like "Name? ". Otherwise the answer is squashed right up against the question.

Answers are always text

This is the number one surprise with input(): even if the person types 12, you get the text "12", not the number 12. To do math with it, convert it with int() (whole numbers) or float() (decimals):

answer"12"text from input()
→ int(answer) →convertint()
age12a real number

int(input(...)) does two things in one line: first input gets the text, then int turns it into a number. Try typing a word instead of a number. You'll get a ValueError, because Python can't turn "hello" into a number. (In lesson 12 you'll learn to handle that politely.)

Common mistakes

  • Forgetting int(): input("Age? ") + 1 is a TypeError, because you can't add a number to text.
  • Adding text that looks like numbers: "5" + "3" is "53", not 8!
  • Not saving the answer: input("Name? ") on its own asks the question, but the answer is lost. Store it: name = input("Name? ").

Remember

  • answer = input("Question? ") asks, waits, and stores what's typed.
  • The answer is always text. Use int(input(...)) or float(input(...)) for numbers.
  • Clean answers with .strip(), .lower() or .title().
