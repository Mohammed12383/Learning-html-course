Lists

A variable holds one thing. A list holds many things, in order: a shopping list, the players in a game, every score this week. Lists and loops together are one of the most powerful tools in programming.

  • Making lists
  • Getting items by position
  • Adding and removing
  • Looping over a list
  • Sorting, counting and more

Many things in one box

A list is written with square brackets [ ], with commas between the items. Like letters in a string, every item has a position (an index) starting at 0:

fruits =
"apple"0
"banana"1
"cherry"2
"mango"3

Lists can hold numbers, text, True/False, or a mix. You can even have an empty list: [].

Changing a list

Unlike strings, lists can be changed. Step through and watch the list grow and shrink:

CodeDoes
items.append(x)Add x to the end
items.insert(i, x)Put x at position i
items[i] = xReplace the item at position i
items.remove(x)Remove the first x found
items.pop()Remove and give back the last item (or pop(i) for position i)
x in itemsTrue if x is in the list
items.index(x)The position of x
items.count(x)How many times x appears

Common mistakes

  • Index out of range: a list of 4 items has positions 0 to 3. items[4] is an IndexError.
  • Forgetting the brackets: fruits = "apple", "banana" isn't quite a list. Use [ ].
  • Storing the result of sort(): new = items.sort() gives None. Use new = sorted(items).
  • Removing something that isn't there: .remove(x) gives a ValueError. Check with if x in items: first.

nums = [5, 10, 15]. What is nums[1]?

Index 0 is 5, index 1 is 10.

Remember

  • items = [a, b, c]. items[0] is the first, items[-1] the last, len(items) the count.
  • .append(), .insert(), .remove(), .pop() change the list.
  • for item in items: visits every item.
  • sum(), min(), max(), sorted(), in. .split() and .join() convert text.
