  • 17 / 5 is 3.4: the exact answer, with decimals.
  • 17 // 5 is 3: how many whole cookies each friend gets.
  • 17 % 5 is 2: how many cookies are left over (the remainder).

The remainder is surprisingly useful

number % 2 is 0 for even numbers and 1 for odd numbers. It's also how clocks work: 14 hours after midnight is 14 % 12 = 2 o'clock.

One more thing: / always gives a decimal number (a float), even when it divides evenly. 6 / 2 is 3.0, not 3.

What's done first?

Python follows the same order as math class: brackets first, then powers, then × and ÷, then + and −. When in doubt, add brackets to make it clear.

Rounding and other number tools

int() and float() convert a value to another type. int("42") turns the text "42" into the number 42. You'll need this in lesson 5, when people type numbers into your programs.

A tiny surprise

Try print(0.1 + 0.2). You get 0.30000000000000004! Computers store decimals in a way that can't be perfectly exact for some numbers. It's normal in every language. Use round() when you show money or results to people.

Common mistakes

  • Using x for multiply: Python uses *. And ^ is not power: use **.
  • Math with text: "5" + 3 is a TypeError. Convert first: int("5") + 3.
  • Dividing by zero: 5 / 0 gives a ZeroDivisionError.
  • Commas in numbers: 1,000 is not one thousand. Write 1000 or 1_000.

What is 20 % 6?

6 goes into 20 three times (18), with 2 left over. % gives the leftover.

What does print(2 + 3 * 2) show?

Multiplication comes first: 3 × 2 = 6, then 2 + 6 = 8.

Remember

  • + - * / for normal math. // whole division, % remainder, ** power.
  • Brackets first, then powers, then × ÷, then + −.
  • round(x, 2), abs(), max(), min().
  • int() and float() convert values into numbers.
