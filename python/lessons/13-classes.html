Classes & Objects

Games have players, monsters and coins. Shops have products and customers. A class lets you create your own kind of thing, with its own information and its own actions. This is called object-oriented programming, and almost every big program uses it.

A blueprint and the things you build

Think of it like this

A class is like a cookie cutter: it describes the shape. The cookies you make with it are objects. One cutter can make as many cookies as you like, and each cookie can have different sprinkles.

An object bundles two things together:

  • Attributes: information about it. A dog has a name and an age.
  • Methods: things it can do. A dog can bark() and have_birthday(). A method is just a function that belongs to the object.

What do __init__ and self mean?

  • class Dog: starts the blueprint. Class names start with a capital letter.
  • __init__ (two underscores on each side) is a special method that runs automatically when you make a new object. It sets up the object's starting information. "init" is short for "initialize".
  • self means "this particular object". self.name = name means "store the name inside this dog". Every method gets self as its first parameter, so it knows which dog it's working on.
  • rex = Dog("Rex", 3) makes a new object. Python calls __init__ with name="Rex" and age=3. You never pass self yourself: Python does it.

Common mistakes

  • Forgetting self as the first parameter of a method: def bark(): should be def bark(self):.
  • Forgetting self. when using attributes: inside a method, write self.name, not just name.
  • One underscore: it's __init__, with two on each side.
  • Forgetting the brackets: rex = Dog doesn't make a dog. rex = Dog("Rex", 3) does.

What does self mean inside a method?

When you call rex.bark(), self is rex. When you call bella.bark(), it's bella.

When does __init__ run?

Dog("Rex", 3) makes the object and runs __init__ right away to set it up.

Remember

  • A class is a blueprint. An object is a thing made from it: rex = Dog("Rex", 3).
  • __init__(self, ...) sets up a new object. self.x = x stores attributes.
  • Methods are functions inside the class, with self first. Call them with obj.method().
  • class Cat(Animal): inherits everything from Animal.
