Your First Program

The very first thing every programmer learns is how to make the computer show something on the screen. In Python, that's print(). You'll also learn to read error messages, which is the most useful skill in programming.

print() shows things

print is a function: a command with a name. You write its name, then round brackets ( ), and inside the brackets you put what you want to show.

Text in quotes is called a string (a "string of letters"). The quotes tell Python where the text starts and ends. They don't appear in the output.

Every print starts a new line. An empty print() prints an empty line, which is handy for adding space.

Printing several things at once

Put several things in one print, separated by commas. Python puts a space between them.

Two extra settings you can add inside print():

  • sep=" | " chooses what goes between the things (normally a space).
  • end="..." chooses what goes at the end (normally a new line). That's why "done!" appeared on the same line.

Quotes, apostrophes and new lines

You can use double quotes "..." or single quotes '...'. Both work the same. Pick the one that doesn't clash with your text:

A backslash \ starts a special code inside text. \n means "new line" and \t means "tab" (a big space).

Comments: notes for humans

Anything after a # on a line is a comment. Python ignores it completely. Use comments to explain your code to yourself and others, or to switch a line off.

Your first error (and how to read it)

Every programmer makes mistakes all day long. Even experts! The computer tells you what went wrong with an error message. Learning to read them is a superpower. This program has a typo on purpose:

Look at the output. An error message tells you three things:

  1. The type of error. NameError means Python doesn't know a name.
  2. The line. Line 2. It's also marked in red in the code, and its number turns red.
  3. The details. name 'prnt' is not defined: Python has never heard of "prnt".

Notice that line 1 still ran, but the program stopped at the error, so line 3 never ran. Now fix the typo: change prnt to print.

Fix one mistake at a time: Python only shows the first error it finds. (Hint: one quote is missing, and Python cares about capital letters.)

Common mistakes

  • Missing quote: print("Hi). Every string needs a quote at both ends.
  • Missing bracket: print("Hi". Every ( needs a ).
  • Capital letters: Print is not print. Python is case-sensitive.
  • Curly quotes like “this” from a word processor or the iPad keyboard. Python needs straight quotes ". On an iPad, press and hold the quote key, or turn off Smart Punctuation in Settings → General → Keyboard.

What does print("2 + 2") show?

The quotes make it text, so Python prints it exactly as written. Without quotes, print(2 + 2) would show 4.

A program has an error on line 3. What happens to lines 1 and 2?

Python runs line by line. Lines 1 and 2 run normally, then the program stops at the error on line 3.

Remember

  • print("text") shows text. print(5 + 3) shows the answer.
  • Commas print several things with spaces. sep= and end= change the spacing.
  • # starts a comment. \n is a new line. """ makes multi-line text.
  • Error messages tell you the type, the line and the details.
