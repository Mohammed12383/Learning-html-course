Loops with for

Computers never get bored. A loop repeats some code as many times as you like: 3 times or 3 million. Loops are how programs draw patterns, count, and go through every item in a list.

Repeat without copying

Say you want to print "Hip hip hooray!" five times. You could copy the line five times. But what about 500 times? A for loop does it in two lines:

Just like if, the lines that repeat are pushed in by 4 spaces. Lines that aren't pushed in run once, after the loop is finished. Change 5 to 50.

Common mistakes

  • Off by one: range(1, 10) stops at 9. To include 10, write range(1, 11).
  • Forgetting to indent the lines that should repeat.
  • Resetting inside the loop: putting total = 0 inside the loop sets it back to 0 every time. It belongs before the loop.
  • Missing colon at the end of the for line.

Which numbers does range(2, 6) give?

range starts at the first number and stops just before the second.

How many stars? for a in range(3): for b in range(4): print("*")

The inner loop prints 4 stars, and it runs 3 times: 3 × 4 = 12.

Remember

  • for i in range(5): repeats the pushed-in lines 5 times, with i = 0, 1, 2, 3, 4.
  • range(start, stop, step) stops before stop.
  • for letter in text: goes through each letter.
  • To add things up: start at 0 before the loop, add inside it.
