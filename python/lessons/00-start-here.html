What is programming?

A computer is very fast, but it can't think for itself. It only does exactly what it's told. A program is a list of instructions for the computer, written in a language it understands. Writing those instructions is called programming (or coding).

Think of it like this

A program is like a recipe. A recipe says: "1. Crack two eggs. 2. Add milk. 3. Stir." The cook follows the steps in order, one at a time. A computer follows your program the same way: line by line, from top to bottom, exactly as written.

How to use this course

Code boxes

  • Run runs the program. Most programs also run again by themselves when you stop typing. On a keyboard, Ctrl+Enter also runs it.
  • Output (on the right, or below on small screens) shows what the program prints and draws.
  • Reset puts the code back to how it started. You can't break anything.
  • Copy copies the code. Stop stops a program that runs too long.
  • When something goes wrong, the output shows the error, the line is marked in red, and a box explains what it means in plain words.

Step-through viewers and explorers

Step-through viewers (like the pancake one above) let you watch a program run line by line and see what's stored in memory. Explorers have sliders: move them and the program changes and runs again.

Running Python on your own computer

Everything in this course runs right here in the page, even on an iPad and even offline. When you want to write Python on a computer too, it takes about ten minutes to set up:

  1. Install Python from python.org/downloads. On Windows, tick the box "Add Python to PATH" during the install.

  2. Install VS Code from code.visualstudio.com, then open the Extensions panel on the left and install Python.

  3. Make a file called hello.py. The .py at the end means "this is Python".

  4. Type print("Hello!") and save the file.

  5. Press the ▶ button at the top right of VS Code. The output appears in the panel at the bottom, called the terminal.

Tip

This course runs a version of Python made for web pages. It does everything you'll learn here. Real Python on a computer can do even more, like opening files and making windows and games.
