How every lesson works

You learn by looking and trying. Each idea comes with a small program you can change and run.

1 · read

A short, simple explanation

Plain words and pictures. Every new word is explained the first time you meet it.

2 · run

Code and result side by side

The code is on the left, what it prints or draws is on the right. Step-through viewers show the program running one line at a time.

3 · try

Change it, break it, fix it

Mistakes are explained in plain English. Small tasks and quizzes help it stick. Reset always brings the code back.
