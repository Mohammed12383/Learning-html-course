Text Boxes & Forms

Sign-up pages, search bars, contact forms, checkout pages: they're all forms. Here you'll learn every kind of box people can type into or pick from, and how to make them look beautiful.

The text box

A text box is made with <input>. Like <img>, it has no closing tag. The type attribute says what kind of box it is.

<inputtag
typekind of box
="text"normal text
placeholdergray hint
="Your name"shown when empty
>

Always add a label

A <label> is the text that says what a box is for. Connect it to its box: give the input an id, and give the label a matching for. Now clicking the label puts the cursor in the box, and screen readers read the label out loud.

Click the words "Your name" in the preview. The cursor jumps into the box. That only works because for="name" matches id="name".

Placeholder is not a label

The placeholder disappears as soon as someone starts typing, so they forget what the box was for. Use a placeholder for an example ("e.g. Sam"), and a label for the name of the box.

Big text boxes and dropdowns

  • <textarea> is a big box for long messages. It does have a closing tag. rows sets how many lines tall it is.
  • <select> makes a dropdown menu. Each choice is an <option>.

Checkboxes and radio buttons

checkbox

Pick any number of choices. Like pizza toppings: you can have cheese and mushrooms.

radio

Pick only one. Like the size: small or large. Radios with the same name belong together.

Two new things: <fieldset> draws a box around a group of choices, and <legend> is the group's title. Also notice another way to connect a label: put the input inside the label. Then you don't need for and id.

The checked attribute picks a choice before anyone clicks.

Sending a form

To send information, put everything inside a <form> and add a submit button. Two important attributes:

  • name: the name of the information when it's sent. Without a name, a box sends nothing!
  • required: the form won't send until this box is filled in. The browser shows a message by itself.

Press Send with the boxes empty: the browser stops you. Fill them in and press Send: a message shows exactly what the website received. Try deleting name="email" and sending again. The email disappears from what was received.

Where does the information go?

A real form needs somewhere to send the information, which is called a server. HTML and CSS can't receive it on their own. When you're ready to make a working contact form, free services like Formspree or Netlify Forms give you an address to put in <form action="...">, and they email you the messages.

Making text boxes beautiful

Default text boxes look old-fashioned. A few lines of CSS make them look modern. The most important one is :focus, the style when someone clicks into the box.

Click into the box in the preview to see the focus style. The 33 at the end of the shadow color is a hex trick: two extra characters make the color see-through (33 is about 20%).

Size guide for forms

  • Text box height: 44 to 48px. That's about padding: 12px 14px with 16px text.
  • Font size: at least 16px. Smaller, and iPhones zoom in when you tap the box.
  • Width: width: 100% of the form, and limit the form with max-width: 400px.
  • Label: above the box, 6 to 8px gap.
  • Between fields: 16 to 20px.

Common mistakes

  • No name on inputs: nothing gets sent.
  • No labels, or labels not connected (for must match id exactly).
  • Radio buttons with different names: then you can select all of them. A group must share one name.
  • Removing the focus style with outline: none and adding nothing instead. People can't see which box they're in.

Which input type lets people pick only one choice from a group?

Radio buttons that share the same name allow only one choice. Checkboxes allow many.

Why does a text box need a name attribute?

The name is the label for the data when it's sent. (Connecting to a label uses id and for.)

Remember

  • <input type="...">: text, email, password, number, date, color, checkbox, radio and more.
  • <label for="x"> + <input id="x"> are connected.
  • <textarea> for long text, <select> + <option> for dropdowns.
  • Inside a <form>, every box needs a name. required makes it compulsory.
  • Style with padding, border, border-radius, and a clear :focus style. 16px text.
