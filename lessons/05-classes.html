Classes, Divs & Sections

So far, a CSS rule changed every element of a kind. Real websites need to style just some things. Classes let you do that, and divs let you group things into boxes you can style.

The problem: styling only some things

This rule makes every paragraph red. But what if only one paragraph is a warning?

The answer is a class. A class is a name you make up and stick on elements, like a label on a box. Then CSS can find everything with that label.

Classes

In HTML, add a class attribute. In CSS, write the class name with a dot in front. The dot means "class".

In HTML

<p class="warning">

In CSS

.warning { color: red; }

Notice the class .warning is used twice. That's the power of classes: write the style once, use it as many times as you want.

More than one class

An element can have several classes. Separate them with spaces. Each class adds its own styles.

Naming classes

Use lowercase words. Use dashes instead of spaces: .main-title, .price-tag, .big-button. Name things by what they are (.warning), not how they look (.red-text), so the name still makes sense if you change the color later.

Ids

An id is like a class, but it's unique: only one element on the page can have it, like a passport number. In CSS, you write it with a hash #.

Ids are mostly used for jump links (href="#top", from the last lesson). For styling, use classes. They're more flexible.

div and span: boxes for grouping

Sometimes you need a box to hold several things together, like a card with a title, a picture and a button. That's what <div> is for. It means "division" (a section). On its own, it doesn't look like anything. It's an invisible box you can style.

<span> is the small version: it wraps a few words inside a line of text.

Block and inline

Every element is one of two kinds:

Block: takes the whole width <div> <p> <h1> <ul>
Each block starts on a new line, stacked like bricks
Inline elements sit inside the line like words, such as span, a and strong.

Press X-ray and point at things. The div.card is as wide as the whole preview, because it's a block. The span.price is only as wide as "$4", because it's inline.

Page sections

HTML has special boxes that work just like <div> but have a meaning. They tell the browser (and Google, and screen readers) what each part of the page is. Most websites are built from these:

<header>logo and site name
<nav>menu links
<aside>extra info
<main>the main content, made of <section>s
<footer>copyright, contact, links
TagUse it for
<header>The top of the page: logo, site name, often the menu.
<nav>A group of navigation links (the menu).
<main>The main content. Only one per page.
<section>A part of the page with its own heading, like "Features" or "Prices".
<article>Something that makes sense on its own: a blog post, a product, a news story.
<aside>Extra side information.
<footer>The bottom of the page.
<div>Any other box, when none of the above fits.

All the ways to select things

A selector is how CSS finds elements. These are the ones you'll use 95% of the time:

SelectorFinds
pEvery <p>
.cardEverything with class="card"
#topThe one element with id="top"
.card pEvery <p> inside a .card (note the space)
h1, h2Every <h1> and every <h2> (note the comma)
a:hoverA link while the mouse is over it (more in the Buttons lesson)
*Every element

When two rules disagree

What if one rule says "red" and another says "blue" for the same element? CSS has simple rules for who wins:

  1. The more specific selector wins. An id beats a class, and a class beats a tag name: #id > .class > p.
  2. If they're equally specific, the one written last wins.

That's why it's called CSS: Cascading Style Sheets. Styles flow down like a waterfall, and later or more specific ones win.

Common mistakes

  • Forgetting the dot in CSS: warning { } looks for a <warning> tag, which doesn't exist. Write .warning { }.
  • Putting the dot in HTML: write class="warning", not class=".warning".
  • Spaces in class names: class="big title" is two classes. Use big-title for one.
  • Using the same id twice. Ids must be unique. Use a class instead.

How do you select class="price" in CSS?

A dot means class. A hash # means id.

Which element is inline (sits inside a line of text)?

<span> wraps words inside a line. <div> and <section> are blocks that take the whole width.

Remember

  • class="name" in HTML, .name { } in CSS. Use classes for styling.
  • id="name" is unique. #name { } in CSS.
  • <div> is a block box for grouping, <span> wraps words.
  • Use header, nav, main, section, footer to build pages.
  • More specific wins. If equal, the last one wins.
