A website is just text

Every website you have ever visited is made from plain text files. Your browser (Chrome, Safari, Edge, Firefox) reads that text and turns it into what you see: titles, pictures, buttons and colors.

That text is called code. It looks strange at first, but it's mostly English words inside little brackets. Here is a real one. The code is on the left. The website it makes is on the right.

Click inside the code and change learning to code to anything you like. The website changes as you type. That's the whole idea of this course: see the code and the result together, and learn by changing things.

The three languages of the web

Websites are built with three languages. Each one has a different job. Think of building a house:

HTML

The walls and rooms. It says what is on the page: a title, a paragraph, a picture, a button.

CSS

The paint and furniture. It says how it looks: colors, sizes, fonts, spacing, layout.

JavaScript

The electricity. It makes things happen: menus that open, games, things that react to clicks.

This course teaches HTML and CSS, which is everything you need to build good-looking websites. You'll get a small taste of JavaScript in the Buttons lesson.

Without CSS, a page looks like a plain document: black text, a basic font, everything on the left. With CSS, the same HTML gets colors, a nicer font and a round button. HTML is the content. CSS is the look.

How to use this course

Playgrounds

A playground is a small code editor next to a pretend browser window. You saw one above.

  • Type in the code and the website updates by itself.
  • Reset puts the code back to how it started. You can't break anything.
  • Copy copies the code so you can paste it into your own file.
  • X-ray draws a line around every part of the website. Point at (or tap) something to see what it is and how big it is in pixels.

Explorers

An explorer has sliders, color pickers and menus. Move them and watch the code and the website change together. The part of the code that changes is highlighted in green.

Making a website on your own computer

You can do every lesson right here in the playgrounds. But building your own site on your computer feels great, and it's easy. You need two free things: a code editor (a program for writing code) and a browser (which you already have).

  1. Install VS Code. It's a free code editor. Get it from code.visualstudio.com.

  2. Make a folder on your computer called my-website. Your website will live in this folder.

  3. Open the folder in VS Code: File → Open Folder → choose my-website.

  4. Make a new file called index.html. The .html at the end tells the computer it's a web page. index.html is the name for a website's home page.

  5. Type ! and press Enter. VS Code writes the basic page skeleton for you. (You'll learn what it means in the next lesson.)

  6. Write something between <body> and </body>, like <h1>Hello!</h1>. Then save with Ctrl+S (Windows) or Cmd+S (Mac).

  7. Open it in your browser: double-click index.html in your folder. Every time you change the code, save and then refresh the browser to see the change.

Tip

In VS Code, install the free Live Server extension (click the Extensions icon on the left and search for it). Then right-click your file and choose Open with Live Server. Your browser will refresh by itself every time you save.

No computer right now?

That's fine. Use the playgrounds in this course on any phone or tablet. There's also a blank page for you in the practice folder of this course.

A secret: you can look at any website's code

On a computer, open any website in Chrome, right-click anything on the page and choose Inspect. A panel opens showing the HTML and CSS of that page. It's the same kind of code you're about to learn. Big sites like YouTube use the exact same tags you'll learn in the next lessons.

Which language decides the colors of a website?

CSS is the styling language. HTML says what is on the page, CSS says how it looks, and JavaScript makes things happen.

Remember

  • A website is text files that the browser turns into a page.
  • HTML = what's on the page. CSS = how it looks. JavaScript = what it does.
  • Web page files end in .html. The home page is called index.html.
