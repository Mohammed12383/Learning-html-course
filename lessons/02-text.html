Headings, Paragraphs & Lists

Most of a website is text. In this lesson you'll learn the tags for titles, paragraphs, important words and lists. With just these, you can already make a real page.

  • Six sizes of headings
  • Paragraphs and line breaks
  • Bold, italic and highlight
  • Bullet and numbered lists
  • Special characters

Headings: h1 to h6

Headings are titles. There are six levels, from <h1> (the biggest, most important) to <h6> (the smallest). The number is the level of importance, like chapters and sub-chapters in a book.

Turn on X-ray in the preview and point at each heading to see how tall it is in pixels. Without any styling, browsers make headings these sizes:

h1 32pxBig title
h2 24pxSection title
h3 19pxSmaller title
h4 16pxSame as normal text, but bold
h5 13pxSmall
h6 11pxTiny

Tip

Use one <h1> per page for the main title. Then use <h2> for each section, and <h3> inside sections. Don't pick a heading just because of its size. Google and people who use screen readers rely on headings to understand your page. You'll change sizes with CSS later.

Paragraphs, line breaks and lines

You already know <p>. Each paragraph starts on a new line with a little space above and below it. Two more useful tags:

  • <br> breaks the line, like pressing Enter. Good for addresses and poems.
  • <hr> draws a line across the page to separate parts.

Bold, italic and more

Inside a paragraph, you can mark special words. These tags sit inside your text and don't start a new line.

Good to know

You might also see <b> (bold) and <i> (italic). They look the same as <strong> and <em>, but <strong> and <em> also tell the browser the words are important. Prefer those.

Lists

Lists are everywhere on websites: menus, features, steps, ingredients. There are two kinds.

<ul>

Unordered list. Bullet points. Use it when the order doesn't matter, like a shopping list.

<ol>

Ordered list. Numbers. Use it when the order matters, like steps in a recipe.

Each item in either list goes inside <li> (list item). The <li> tags always sit inside the <ul> or <ol>.

<ul>
<li>Flour
<li>Eggs
<li>Milk

Lists inside lists

You can put a whole list inside a list item. This is how websites make menus with sub-menus.

Special characters and emoji

Because < and > are used for tags, you can't type them directly in your text. Use these short codes instead. They're called entities and they start with & and end with ;.

Type thisTo get
&lt;< (less than)
&gt;> (greater than)
&amp;& (and)
&copy;© (copyright)
&nbsp;a space that never breaks onto a new line

Emoji work directly. Just paste them in: 🍰 🌸 ✨. (That's why the skeleton has <meta charset="utf-8">.)

Common mistakes

  • Using a heading to make text big. Pick headings for their meaning. Size comes from CSS.
  • Putting <li> without a <ul> or <ol> around it. List items always live inside a list.
  • Pressing Enter to make a new line. Use a new <p> or a <br>.
  • Skipping heading levels (h1 then h4). Go in order: h1, h2, h3.

Which list would you use for the steps of a recipe?

Steps have an order, so use an ordered list <ol>. It numbers them for you: 1, 2, 3.

How many <h1> headings should a page usually have?

One <h1> for the main title. Sections use <h2>.

Remember

  • <h1> to <h6> for titles, most important first.
  • <p> for paragraphs, <br> for a new line, <hr> for a dividing line.
  • <strong> bold, <em> italic, <mark> highlight.
  • <ul> bullets, <ol> numbers, <li> for each item.
