The button tag

A button is made with <button>. Without CSS, it's small, gray and plain:

Button or link?

Buttons and links can look the same, but they do different jobs. Use the right one:

<a>

Goes somewhere. Another page, another website, a section. "Read more", "About us", "Download".

<button>

Does something on this page. Sends a form, opens a menu, adds to a cart, plays a video.

Design your own button

A good-looking button is mostly five properties: background color, text color, padding, rounded corners, and no border. Play with them:

Every line explained:

LineWhy
background-colorThe fill color. Use your main brand color.
colorThe text color. Make sure it's easy to read on the background.
padding: 14px 28pxSpace inside the button. More on the sides than top and bottom, so it's wider than tall.
border-radiusRound corners feel friendly. 999px makes a pill.
border: noneRemoves the browser's default gray border.
font-size, font-weightButtons usually have 16px text and are a bit bold.

Making buttons react: hover and press

A great button reacts when you touch it. CSS has special selectors for the state of an element. They're written with a colon after the selector and are called pseudo-classes.

buttonwhich element
:hoverwhen the mouse
is over it
{ ... }these styles
StateWhen
:hoverThe mouse pointer is over it.
:activeIt's being pressed down right now.
:focus-visibleSomeone moved to it with the Tab key on the keyboard.
:disabledIt's switched off and can't be clicked.

Three new things in there:

  • cursor: pointer turns the mouse arrow into a hand, so people know it's clickable.
  • transform: translateY(-3px) moves the button up 3 pixels. It looks like it's lifting toward you.
  • transition: all 0.2s ease makes the change smooth over 0.2 seconds instead of jumping instantly. Delete this line and hover again to feel the difference.

Phones don't have hover

On a touch screen there's no mouse, so :hover barely happens. Never hide important information behind hover. Use it as a nice extra for computers. :active works on phones while your finger presses.

How to use button styles together

Use a solid button for the most important action ("Sign up"), and an outline or ghost button for the less important one next to it ("Learn more"). One loud button per area, so people know what to click first.

Common mistakes

  • Forgetting cursor: pointer, so the button doesn't feel clickable.
  • Tiny buttons. Make them at least 44px tall so fingers can tap them.
  • Hard-to-read colors, like white text on a light yellow button.
  • Removing the focus outline without adding another one. Keyboard users need to see where they are.

Which selector styles a button while the mouse is over it?

States use a colon: :hover, :active, :focus-visible.

What does transition: all 0.2s ease; do?

Instead of jumping from one look to another, the change is animated smoothly.

Remember

  • <button> does something. <a> goes somewhere.
  • Pretty button = background, color, padding, border-radius, border: none.
  • :hover, :active, :focus-visible for states. Add cursor: pointer.
  • transition makes changes smooth. transform: translateY(-2px) lifts.
