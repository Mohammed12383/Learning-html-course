Sizes & Units

How big should a button be? How wide is a phone? What's the difference between px, % and rem? This lesson explains every size you need, and ends with a size guide you can keep coming back to.

What is a pixel?

Your screen is made of millions of tiny squares of light called pixels. Every picture, letter and button is drawn with them. In CSS, sizes are usually measured in pixels, written px.

One pixel is very small. Normal text is about 16 pixels tall. A phone screen is about 390 pixels wide.

Good to know

Phones with very sharp screens use 2 or 3 tiny dots for each CSS pixel. You don't need to worry about that: 16px in CSS looks about the same size on every screen.

width and height

Every element is a rectangle. width sets how wide it is and height sets how tall it is.

Turn on X-ray and point at the box: the size it shows matches your numbers exactly.

Let height be automatic

Usually you don't set a height. When you leave it out, the box grows to fit whatever is inside (this is called height: auto). If you set a fixed height and the text is longer than you expected, it spills out of the box.

The units

Pixels aren't the only unit. Some units are fixed (always the same size), and some are relative (they depend on something else, like the screen size). Here are the ones you'll actually use:

UnitMeansUse it for
pxPixels. Always the same size.Borders, shadows, small details, rounded corners
%Percent of the box it's inside (its parent).Widths that stretch, like width: 100%
remTimes the page's normal text size. 1rem = 16px.Font sizes and spacing
emTimes this element's own text size.Padding inside buttons, so it grows with the text
vwPercent of the screen's width. 100vw = full width.Big titles that grow with the screen
vhPercent of the screen's height. 100vh = full height.A first section that fills the screen

Set the number to 10 and switch units: 10px is tiny, 10rem is 160px, 10% is a tenth of the preview, and 10vw is a tenth of the screen. Then try Phone and Laptop under the preview and watch which ones change.

Percent: a share of the parent

% is always a share of the box an element is inside. If the parent is 400px wide, width: 50% makes the child 200px.

rem: sizes based on text

Browsers start text at 16px. 1rem is that size. Many designers use rem for fonts and spacing, because if someone sets bigger text in their browser (to read more easily), everything grows with it.

Quick math: rem × 16 = pixels. Both are fine to use. If you find px easier to think about, use px.

vw and vh: sizes based on the screen

The section is always exactly as tall as the screen (100vh), and the title is 8% of the screen's width. Switch between Phone and Laptop to see it scale.

max-width: not too wide

On a big screen, content stretched across the whole width looks empty and is hard to read. max-width says "be as wide as you can, but never wider than this". On a phone the box shrinks to fit, and on a laptop it stops growing.

Add margin: 0 auto and the box sits in the center. (You'll learn exactly why in the next lesson.)

Almost every website wraps its content in a box like this. Common sizes are max-width: 1100px for the whole page and max-width: 700px for text.

There's also min-width ("never narrower than") and min-height ("at least this tall, but grow if needed"), which is safer than a fixed height.

Why 44px for buttons?

A fingertip is about 44 pixels wide on a phone screen. Anything smaller is hard to tap. This is why buttons and text boxes should be at least 44px tall.

Common mistakes

  • Forgetting the unit: width: 200; does nothing. Write width: 200px;. (Only 0 works without a unit.)
  • A space before the unit: 16 px doesn't work. Write 16px.
  • Fixed heights on text boxes. Long text spills out. Use min-height or no height.
  • Width wider than the phone: width: 800px makes phones scroll sideways. Use max-width instead.

If the normal text size is 16px, how big is 2rem?

rem × 16 = pixels, so 2 × 16 = 32px.

You want a box to fill its parent, but never be wider than 800px. What do you write?

max-width lets the box shrink on small screens but stops it at 800px on big ones. width: 800px would be too wide for a phone.

Remember

  • px is fixed. % is part of the parent. rem is times 16px. vw/vh are parts of the screen.
  • Usually let height be automatic.
  • max-width + margin: 0 auto makes a centered page.
  • img { max-width: 100%; height: auto; } on every site.
  • Text 16px. Buttons 44px+ tall. Spacing from 4, 8, 16, 24, 32, 48, 64.
