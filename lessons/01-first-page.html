Your First Web Page

HTML is a way of labeling things. You put labels called tags around your words, and the browser knows what each part is: a title, a paragraph, a picture.

Tags: labels for your content

A tag is a word inside angle brackets < >. Most tags come in pairs: an opening tag and a closing tag. The closing tag has a slash / in it. The content goes between them.

<p>opening tag
Hello!content
</p>closing tag
(has a /)

The whole thing together (opening tag + content + closing tag) is called an element. The p stands for paragraph. Tag names are short on purpose, so they're quick to type.

<h1> means "heading 1", the main title. It's big and bold. Each <p> is a paragraph, and each one starts on a new line.

  2. Add a third paragraph: type <p>, some words, then </p>.
  3. Delete the </p> at the end of a line. What happens? (Usually nothing breaks yet, because browsers are forgiving. But always close your tags. Missing ones cause strange problems later.)

Attributes: extra information

Some tags need more information. For a picture, the browser needs to know which picture. You give that information with an attribute, written inside the opening tag.

An attribute always looks like name="value". Think of attributes as settings. Here, src (short for "source") says which picture file to show, and alt describes it in words.

Try changing 200 to 100 or 300. Did you notice <img> has no closing tag? Some tags have no content inside them, so they don't need one. These are called empty tags. Other empty tags are <br> (line break) and <hr> (a line across the page).

Tags inside tags

You can put elements inside other elements. This is called nesting. It's like boxes inside boxes.

<body>
<h1>My Trip to the Beach
<p> The water was
<strong>really warm

<strong> makes words bold and important. It sits inside the paragraph. The rule for nesting is simple: close the inside box before the outside box.

To keep nesting easy to see, we push inside elements a little to the right with spaces. This is called indenting. The browser doesn't care about it, but it makes code much easier for humans to read.

The page skeleton

The playgrounds so far only showed small pieces. A real web page file always has the same basic structure around your content. It's like the frame of a house. Here's the full skeleton:

Look at the top of the pretend browser: My First Website appears there. That comes from the <title>. Change it and watch it update.

<head>

Backstage. Information about the page, for the browser and for Google. Nothing in here shows on the page itself.

<body>

The stage. Everything people see: text, pictures, buttons. Almost all of your work goes in here.

What each line means

LineWhat it does
<!DOCTYPE html>Tells the browser "this is a modern HTML page". Always the very first line.
<html lang="en">Wraps the whole page. lang="en" says the page is in English.
<head>Starts the backstage part.
<meta charset="utf-8">Lets your page show every letter and emoji correctly (é, ñ, 你好, 😀).
<meta name="viewport" …>Makes the page fit phone screens. Always include it.
<title>The name shown on the browser tab and in Google results.
<body>Starts the visible part. Your content goes here.

Tip

You don't need to memorize this. In VS Code, type ! and press Enter, and it writes the whole skeleton for you. There's also a ready-made one in this course's practice/index.html.

Comments: notes for yourself

A comment is a note in your code that the browser ignores. It never shows on the page. Use comments to remind yourself what something is for. They start with <!-- and end with -->.

Comments are also handy for switching code off without deleting it. Try removing the <!-- and --> around the last paragraph.

Spaces and new lines don't count

This surprises everyone: the browser ignores extra spaces and new lines in your text. Many spaces become one space. Pressing Enter doesn't start a new line.

To start a new line, use <br> (line break), or start a new paragraph with a new <p>. To add space between things, you'll use CSS later.

Common mistakes

  • Forgetting the slash in a closing tag: <p>Hi<p> should be <p>Hi</p>.
  • Typos in tag names: <h> or <pp> mean nothing to the browser.
  • Missing quotes around attribute values: write alt="My cat", not alt=My cat.
  • Putting visible content in the <head>. It goes in the <body>.

Which one is a closing tag?

The closing tag has a slash right after the <. It tells the browser where the element ends.

Where do you put the things people should see?

The body is the stage. The head is backstage information like the title and settings.

Remember

  • <tag>content</tag> makes an element.
  • Attributes are settings inside the opening tag: name="value".
  • Close the inside tag before the outside tag.
  • Every page has a skeleton: <!DOCTYPE>, <html>, <head>, <body>.
  • Comments <!-- like this --> are notes that don't show.
