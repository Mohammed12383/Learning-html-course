Links & Images

Links are what make the web a web: they connect pages together. Images make pages come alive. Both use attributes to say where to go or what to show.

Links

A link uses the <a> tag (short for anchor). The href attribute says where the link goes. The text between the tags is what people click.

Click the links in the preview. Links don't leave the playground (so you don't lose your place), but a message tells you where they would go. By default links are blue and underlined. You'll change that with CSS later.

Opening a new tab

Add target="_blank" to open the link in a new browser tab. This is good for links to other websites, so people don't leave yours.

Different kinds of links

The href can point to many places:

Link toWrite the href like this
Another websitehref="https://www.google.com"
Another page of your sitehref="about.html"
A part of the same pagehref="#contact"
An email addresshref="mailto:hi@example.com"
A phone numberhref="tel:+96812345678"

Jumping to a part of the page

Give any element an id (a unique name). Then link to it with # plus the name. Clicking the link scrolls to that spot. This is how "Back to top" buttons and long-page menus work.

Images

Pictures use the <img> tag. It has no closing tag. It needs two attributes:

  • src (source): where the picture file is.
  • alt (alternative text): a short description of the picture. People who can't see it hear this read aloud, and it shows if the picture fails to load.

Where pictures come from

The src is a path: directions to the file. Most websites keep pictures in a folder called images, next to the HTML files.

my-website/
├── index.html        ← this page uses src="images/cat.jpg"
└── images/
    ├── cat.jpg
    └── beach.png

You can also use the full address of a picture on the internet, like src="https://example.com/photo.jpg". But it's safer to keep your own copy in your folder, because pictures on other sites can disappear.

Tip

Big photos from a phone are often 4000 pixels wide and several megabytes. That makes your site slow. Before you use one, shrink it to about 1600 pixels wide with a free tool like squoosh.app.

Clickable pictures and captions

Put an <img> inside an <a> and the whole picture becomes a link. To add a caption under a picture, wrap it in <figure> and add a <figcaption>.

Common mistakes

  • Wrong file name. Cat.JPG and cat.jpg are different on most web servers. Use lowercase names.
  • Spaces in file names. Use my-photo.jpg, not my photo.jpg.
  • Forgetting https:// in links to other sites. href="google.com" looks for a file called google.com in your folder.
  • Missing alt. Always describe your pictures.

Which attribute tells an image which picture file to show?

src (source) is the picture's path. href is for links, and alt describes the picture.

How do you link to a section with id="menu" on the same page?

A # followed by the id jumps to that element.

Remember

  • <a href="where">text</a> makes a link. Add target="_blank" for a new tab.
  • <img src="file" alt="description"> shows a picture. No closing tag.
  • Keep pictures in an images folder. Use lowercase names with no spaces.
