Spacing: The Box Model

Good spacing is the biggest difference between a messy website and a beautiful one. Every element is a box with layers of space around it. Once you understand these layers, you can place anything exactly where you want.

Every element is a box

Every element on a page is a rectangle with four layers, from the inside out:

border

LayerWhat it is
contentThe text or picture itself.
paddingSpace inside the box, between the content and the edge. It has the box's background color.
borderThe edge of the box. A line you can see (or not).
marginSpace outside the box, pushing other things away. Always see-through.

Think of it like this

Imagine a framed photo on a wall. The photo is the content. The white card around the photo is the padding. The wooden frame is the border. The empty wall between this frame and the next one is the margin.

Move the padding slider: the white area grows, because padding is inside the box. Move the margin: the yellow gap around and between the boxes grows, because margin is outside.

Turn on X-ray too. You'll see that padding and border make the box bigger, but margin doesn't.

With four values, think of the word TRouBLe: Top, Right, Bottom, Left.

Rounded corners

border-radius rounds the corners. Bigger number, rounder corner. Round corners make a design feel soft and friendly.

  • border-radius: 50% on a square makes a circle. Great for profile pictures.
  • border-radius: 999px on a wide box makes a pill shape. Great for buttons and tags.
  • You can round each corner differently: border-radius: 40px 0 40px 0 (top-left, top-right, bottom-right, bottom-left).

Margin: space outside

Margin pushes things away from each other. Two very useful tricks:

  • margin: 0; removes the space browsers add on their own. The <body> has 8px of margin by default, and headings and paragraphs have some above and below.
  • margin: 0 auto; centers a box that has a width or max-width. auto means "split the leftover space equally on the left and right".

A strange thing about margins

When two boxes stack on top of each other, their top and bottom margins don't add up. If one has a 20px bottom margin and the next has a 30px top margin, the gap is 30px (the bigger one), not 50px. This is called margin collapsing. It's normal, and good to know when a gap looks smaller than you expected.

box-sizing: the setting everyone uses

Here's a surprise. If you set width: 200px and then add padding: 20px and a 5px border, the box becomes 250px wide! The padding and border are added on top of the width. That makes sizes confusing.

The fix is one line: box-sizing: border-box;. Now padding and border fit inside the width, so a 200px box stays 200px.

Shadows

box-shadow adds a shadow behind a box, making it look like it's floating above the page. It takes: how far right, how far down, how blurry, and a color (usually a see-through black).

Shadow recipes

  • Soft and modern: 0 10px 30px rgba(0, 0, 0, 0.08)
  • Small, for buttons: 0 2px 6px rgba(0, 0, 0, 0.15)
  • Fun, flat and solid: 6px 6px 0 #1F1D2E (no blur)
  • Colored glow: 0 10px 25px rgba(255, 92, 138, 0.4)

Big blur with a light color looks the most natural. Dark, sharp shadows look old-fashioned (unless that's the style you want).

Common mistakes

  • Mixing up padding and margin. Space inside the background = padding. Space between boxes = margin.
  • Wrong border order: border: solid 2px usually works, but always write width, style, color to be safe.
  • Forgetting the style: border: 2px hotpink shows nothing. It needs solid.
  • Forgetting box-sizing, then wondering why boxes are too wide.

You want more space between the text and the edge of its colored box. Which property?

Padding is the space inside the box, between the content and the edge.

What does margin: 10px 20px; mean?

With two values, the first is top and bottom, the second is left and right.

Remember

  • content → padding (inside) → border (edge) → margin (outside).
  • 1 value = all sides. 2 values = top/bottom, left/right. 4 values = top, right, bottom, left.
  • border: 2px solid color; and border-radius for round corners.
  • box-shadow: 0 10px 30px rgba(0,0,0,0.08); for a soft shadow.
  • Start every stylesheet with * { box-sizing: border-box; }
