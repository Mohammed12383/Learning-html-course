Fonts & Text Style

The font is the personality of your website. A round, friendly font feels fun. A thin, elegant font feels fancy. In this lesson you'll learn to choose fonts and control size, weight and spacing.

font-family: choosing a font

The font-family property picks the font. You give a list, separated by commas. The browser uses the first one it has. If it doesn't have that font, it tries the next one. These backups are called fallbacks.

font-family: property
Georgia, 1st choice
"Times New Roman", 2nd choice

any serif font

Always end the list with a general family, so there's always something that works:

General familyWhat it looks like
sans-serifClean, modern letters without little feet. Most websites use this.
serifLetters with little "feet", like in books and newspapers.
monospaceEvery letter is the same width, like code.
cursiveLike handwriting.
system-uiThe font your phone or computer uses for its menus.

Set the font once, on the body

Text styles are inherited: elements inside another element get its font and color too. So put your main font on body, and the whole page uses it. Then only change the font for headings if you want something different.

Google Fonts: 1,500+ free fonts

The fonts above are already on every computer, but they're a bit boring. Google Fonts has more than a thousand free fonts you can use on any website. Here's how:

  1. Go to fonts.google.com and click a font you like, for example Poppins.

  2. Click Get font, then Get embed code.

  3. Copy the <link> lines and paste them into your page's <head>.

  4. Use the font name in your CSS: font-family: "Poppins", sans-serif;

The <link> tag loads the font from Google. It has no closing tag. Try changing Pacifico to Lobster in both places (the link and the CSS).

Size, weight and spacing

Move the sliders to see what each property does.

PropertyWhat it doesGood values
font-sizeHow big the letters are.16px for normal text, 32px to 64px for big titles
font-weightHow thick (bold) the letters are. 400 is normal, 700 is bold.400 for text, 600 to 800 for titles
line-heightThe space between lines. 1.5 means 1.5 times the font size.1.5 to 1.7 for paragraphs, 1.1 to 1.2 for big titles
letter-spacingThe space between letters.0 usually. A little extra for small capital labels.

Why line-height has no unit

line-height: 1.5 means "1.5 times the font size". If the text gets bigger, the space between lines grows with it. That's why it's usually written without px.

Readable text

Long lines are tiring to read, because your eyes get lost going back to the start of the next line. Keep paragraphs about 60 to 75 characters wide. The ch unit is the width of one character, so max-width: 65ch is perfect.

Press Laptop 1280 under the preview: even on a wide screen, the text stays a comfortable width in the middle.

Text shadow

A soft shadow behind text can make it pop. text-shadow takes: how far right, how far down, how blurry, and a color.

Common mistakes

  • Font names with spaces need quotes: "Times New Roman", "Playfair Display".
  • Using a Google Font without the <link>. The browser doesn't have it, so it uses the fallback.
  • Text too small. Normal text should be at least 16px.
  • Too many fonts. Two is plenty. Three at most.

Which font-weight is normal (not bold) text?

400 is normal and 700 is bold. You can also write normal and bold.

Why end font-family with something like sans-serif?

If the computer doesn't have your first choices, the browser uses any sans-serif font instead of an ugly default.

Remember

  • font-family: "Poppins", sans-serif; with a fallback at the end.
  • Google Fonts: paste the <link> in the head, then use the name.
  • font-size, font-weight, line-height, letter-spacing.
  • text-align, text-transform, text-decoration.
  • Set your main font on body. Keep lines about 65 characters wide.
