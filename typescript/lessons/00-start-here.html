What is a program?

A program is a list of instructions for the computer, written in a language it understands. The computer follows them one at a time, top to bottom, exactly as written. Writing those instructions is called programming or coding.

The code is on the left. What it shows is on the right, in the output. Change the text inside the quotes. When you stop typing, it runs again by itself.

JavaScript and TypeScript

JavaScript is the programming language of the web. Every web browser understands it, and almost every website uses it to do things: open menus, play videos, check forms, run games.

TypeScript is JavaScript with one superpower added: types. A type says what kind of value something is: a number, some text, true/false. TypeScript checks your code while you type and warns you about mistakes before your program even runs.

Think of it like this

TypeScript is like a spell-checker for code. A spell-checker underlines "teh" before you send your message. TypeScript underlines mistakes like "you're trying to do math with a word" before you run your program.

Your first type error

Here, a box called age is meant to hold a number. Line 3 tries to put text into it. Look: the line is marked in red and an explanation appears under the code, before the program runs.

Fix it by changing "twelve" to 13. The red line disappears. In plain JavaScript, there would be no warning: the mistake would only show up later, maybe as a confusing bug on a real website. That's why many big apps, like VS Code, Slack and Airbnb, are written in TypeScript.

How TypeScript runs

Browsers only understand JavaScript. So TypeScript is first compiled: a program called the compiler checks the types, then removes them, leaving plain JavaScript that the browser runs.

In this course, the real TypeScript compiler runs inside this page, so you never have to think about it. It even works offline.

How to use this course

  • Run runs the program (Ctrl+Enter on a keyboard). Most examples also run again by themselves when you stop typing.
  • Output shows what console.log prints. Some examples show a web page instead, which you can click and type in.
  • Type errors appear under the code with the line number and a plain explanation. Runtime errors (problems while running) appear in the output.
  • Reset brings the code back. Copy copies it.
  • Step-through viewers show a program running one line at a time. Explorers have sliders that change the code.

Code is colored to help you read it, the same way everywhere:

TypeScript on your own computer

  1. Quickest: the official TypeScript Playground runs TypeScript in your browser, like these code boxes.

  2. On a computer: install VS Code (it understands TypeScript already) and Node.js from nodejs.org.

  3. Make a file called hello.ts and write console.log("Hi!");

  4. Open the terminal in VS Code (View → Terminal) and type npx tsx hello.ts to run it. You'll learn more about real projects in lesson 15.

What does TypeScript add to JavaScript?

TypeScript is JavaScript plus types. The types let it warn you about mistakes while you type.

Remember

  • A program is a list of instructions, run top to bottom.
  • JavaScript is the language of the web. TypeScript is JavaScript with types.
  • The compiler checks types, then turns TypeScript into JavaScript.
  • Type errors appear in red under the code. Read them: they help you.
