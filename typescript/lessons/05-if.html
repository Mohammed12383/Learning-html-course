Why three equals signs?

= stores a value. === compares two values. There's also an old == that tries to be clever: it says 5 == "5" is true, even though one is a number and one is text. That cleverness causes bugs, so always use === and !==.

Look at the last line. A number can never be equal to a string, so TypeScript warns you. In plain JavaScript you'd just quietly get false and wonder why.

And, or, not

  • && means and: both must be true.
  • || means or: at least one must be true.
  • ! means not: flips true and false.

Common mistakes

  • One = instead of three inside the brackets: if (x = 5) stores 5! TypeScript usually warns you.
  • Forgetting the round brackets around the question, or the curly brackets around the block.
  • Forgetting break in a switch case.

Which operator should you use to compare two values?

=== compares without any surprising conversions. = stores a value.
