Loops

A loop repeats code. Instead of writing the same line 100 times, you write it once and tell the computer how many times to repeat it. Loops count, search, draw patterns and go through lists.

The for loop

The classic loop has three parts in its brackets, separated by semicolons:

for (
let i = 0;1. start:
i begins at 0
i < 5;2. keep going
while this is true
i++3. after each round,
add 1 to i
) { ... }the code to repeat

Common mistakes

  • Off by one: i < 10 stops at 9. Use i <= 10 to include 10.
  • Commas instead of semicolons in for ( ; ; ).
  • Never changing the variable in a while loop, so it never ends.
  • Resetting inside the loop: let total = 0 belongs before the loop.

How many times does this run? for (let i = 0; i < 4; i++)

i is 0, 1, 2, 3. When i reaches 4, 4 < 4 is false and the loop ends.

Remember

  • for (let i = 0; i < n; i++) { }: start, keep going while, after each round.
  • while (question) { } when you don't know how many rounds.
  • for (const x of things) { } for each item.
  • break leaves, continue skips to the next round.
