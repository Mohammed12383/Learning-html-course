Variables & Types

A variable is a box with a name that holds a value. In TypeScript, each box also has a type: a label that says what kind of value is allowed inside. Put the wrong kind in, and TypeScript tells you.

Unlike some languages, TypeScript has just one number type for whole numbers and decimals.

let can change, const can't

There are two ways to make a variable:

  • let: the value can change later.
  • const (short for "constant"): the value can never change. Use it whenever you can. It prevents accidents.

TypeScript stops you: a const can't be changed. If a value needs to change, use let.

TypeScript can guess the type

You don't always need to write the type. If you give a starting value, TypeScript works out the type by itself. This is called type inference. The type is still there, and still checked:

typeof tells you the type of a value while the program runs. Fix line 6 by using a number, like 35.

When to write the type

When there's a starting value, let TypeScript guess: let score = 0;. When there's no starting value yet, write the type: let winner: string;. In VS Code, hover over any variable to see its type.

Common mistakes

  • Using a variable before making it: TypeScript says "Cannot find name" or "used before being assigned".
  • Making the same name twice with let: "Cannot redeclare block-scoped variable". Just assign the new value: score = 5;.
  • Changing a const: use let if it must change.
  • Capitals in types: it's string, number, boolean, all lowercase.

Which line has a type error?

y is meant to hold a string, but 5 is a number. The last line is fine: TypeScript infers that z is a string.

You want a variable that never changes. Which keyword?

const means constant. (var is an old way of making variables that you'll see in old code. Use let and const instead.)

Remember

  • let name: type = value; makes a variable that can change. const can't change.
  • Types: string, number, boolean.
  • With a starting value, TypeScript infers the type. It still checks it.
  • Use camelCase names: playerName, highScore.
