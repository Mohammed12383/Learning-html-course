Arrays

An array is a list of values in order: the songs in a playlist, the messages in a chat, the scores in a game. In TypeScript, an array also knows what type its items are, so nothing wrong can sneak in.

A list in one variable

Arrays use square brackets, with commas between the items. Each item has an index, starting at 0:

fruits =
"apple"0
"banana"1
"cherry"2
"mango"3

The type of an array is the type of its items followed by []: string[] means "an array of strings", number[] means "an array of numbers".

Looping over an array

forEach runs a little function for every item. The (friend, index) => { ... } part is an arrow function: a quick way to write a function. You'll learn all about them in lesson 9.

map, filter and reduce

These three are the superstars of arrays. Each one takes a small function and uses it on every item:

[1, 2, 3, 4]
.map(n => n * 2)   change every item
[2, 4, 6, 8]
.filter(n => n > 4)   keep only some
[6, 8]
.reduce((sum, n) => sum + n, 0)   combine into one
14

Math.max(...scores) uses the spread ... to pass every item to Math.max at once.

Sorting (with a trap)

By default, sort() sorts everything as text, so "100" comes before "9" (like in a dictionary). For numbers, give it a compare function: (a, b) => a - b. Also, sort() changes the original array, so [...nums] makes a copy first.

Common mistakes

  • Off by one: the last item is a[a.length - 1], not a[a.length] (that's undefined).
  • Sorting numbers without a compare function.
  • Forgetting that map and filter make a new array: store the result, like const big = nums.filter(...).

What does [1, 2, 3].map(n => n + 10) give?

map uses the function on every item and makes a new array of the results.

Remember

  • const a: number[] = [1, 2, 3];. a[0], a.at(-1), a.length.
  • push/pop at the end, unshift/shift at the start.
  • map changes every item, filter keeps some, reduce combines into one.
  • Sort numbers with .sort((a, b) => a - b).
