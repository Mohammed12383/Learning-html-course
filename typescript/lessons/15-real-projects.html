tsconfig.json: TypeScript's settings

Every TypeScript project has a tsconfig.json file with settings for the compiler. The most important one is "strict": true, which turns on all the safety checks. (This course uses strict mode too.)

Then npx tsc checks every file and turns them into JavaScript. When there's a type error, the terminal shows the file, line and message, just like the boxes in this course.

Start a real project with Vite

Vite is a popular free tool that sets up a TypeScript web project for you and shows your page live in the browser, updating as you save. On a computer with Node.js installed:

  1. Open a terminal and type npm create vite@latest my-app. Choose Vanilla, then TypeScript.

  2. Go into the folder and install: cd my-app then npm install.

  3. Start it: npm run dev. Open the address it shows (like http://localhost:5173).

  4. Edit src/main.ts in VS Code and save. The browser updates instantly.

  5. When it's finished, npm run build makes a dist folder you can put online with Netlify or GitHub Pages (see HTML lesson 13).
