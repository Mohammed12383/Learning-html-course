TypeScript + Web Pages

This is where everything comes together. HTML builds the page, CSS makes it pretty, and TypeScript makes it do things: react to clicks, respond to typing, add and remove things. Every example in this lesson is a real, working web page.

The page is an object called document

When a browser loads HTML, it turns every tag into an object that your code can read and change. All of them live inside an object called document. This is called the DOM (Document Object Model). Each example below has two tabs: main.ts (the code) and index.html (the page). Click the tabs to see both.

  • querySelector takes the same selectors as CSS: "#title" (an id), ".card" (a class), "button" (a tag).
  • The type in angle brackets tells TypeScript what kind of element you'll get, so it knows which properties exist (a button has different properties from an input).
  • If nothing matches, querySelector gives null. The ! at the end tells TypeScript "trust me, it's there". Remove the ! and you'll see TypeScript worry that it might be null.
  • .textContent is the text inside. .style.color, .style.fontSize and so on change the CSS (in camelCase: font-size becomes fontSize).

Reacting to clicks

addEventListener says "when this happens, run this function". The thing that happens is called an event: a click, a key press, typing, scrolling...

classList.toggle("on", liked) adds the CSS class on when liked is true and removes it when false. Changing classes is the cleanest way to change how things look: the CSS describes each look, and TypeScript just switches between them.

Common mistakes

  • Wrong selector: "title" finds a <title> tag. For id="title", write "#title".
  • Forgetting preventDefault() in a submit event: the page reloads and everything is lost.
  • Doing math with input.value: it's a string. Use Number(input.value) or input.valueAsNumber.
