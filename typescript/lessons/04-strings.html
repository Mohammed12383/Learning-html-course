Template strings: the easy way

You can join strings with +, but it gets messy. Template strings are much nicer. Use backticks ` instead of quotes, and put any value inside ${ }:

`Hi backtick + text
${name}a value dropped in
!`closing backtick

On an iPad keyboard, the backtick is on the numbers page: press and hold the apostrophe key. On most computer keyboards it's top left, under Esc.

String methods

Strings come with lots of built-in methods, used with a dot. In VS Code, type a dot after a string and a list of every method pops up. That list exists because TypeScript knows the value is a string.

MethodDoes
.toUpperCase() / .toLowerCase()CAPITALS / small letters
.trim()Remove spaces at the start and end
.includes(x)true if x is inside
.startsWith(x) / .endsWith(x)true or false
.indexOf(x)Position of x (−1 if not found)
.replace(a, b) / .replaceAll(a, b)Swap the first a / every a for b
.slice(start, end)Cut out a piece
.split(sep)Break into an array (lesson 7)
.repeat(n) / .padStart(n, c)Repeat / pad to a length

Methods never change the original string. They give you a new one.

Common mistakes

  • Quotes instead of backticks: "Hi ${name}" shows the ${name} literally.
  • Counting from 1: the first character is [0].
  • length with brackets: it's text.length, not text.length(). TypeScript will tell you.

name is "Mo". Which line shows Hi Mo?

Only backticks make ${ } work. The last one gives "HiMo" with no space.

Remember

  • `Hi ${name}` builds text with values inside.
  • text[0], text.at(-1), text.length, text.slice(a, b).
  • Methods: toUpperCase, trim, includes, replace, split.
