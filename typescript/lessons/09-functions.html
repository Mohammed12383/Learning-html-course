Functions

A function is a mini-program with a name: write it once, use it whenever you need it. In TypeScript, a function also says what types it takes in and what type it gives back, so it can never be used the wrong way.

Optional and default values

  • topping: string = "cheese" has a default value, used when you leave it out.
  • extra?: string is optional. If it's left out, it's undefined, so the code checks if (extra) before using it.

Arrow functions

There's a shorter way to write functions, with an arrow =>. Arrow functions are used everywhere in modern TypeScript, especially for small functions:

When an arrow function is just one expression, you don't need { } or return: n => n * 10 returns n * 10. Inside map, TypeScript already knows n is a number, so you don't need to write the type.

Common mistakes

  • Forgetting to call it: writing function doesn't run it. Call it with name().
  • Forgetting return: if the return type is number but you don't return, TypeScript warns you.
  • Logging instead of returning: console.log only shows the answer. return hands it back so you can use it.

const triple = (n: number) => n * 3. What is triple(4) + 1?

triple(4) returns 12, then 12 + 1 = 13.

Remember

  • function name(p: type): returnType { return ...; }
  • Call it: name(value). TypeScript checks the types and the number of values.
  • void means nothing is returned. p?: type optional, p = value default.
  • Arrow functions: const f = (a: number) => a * 2;
