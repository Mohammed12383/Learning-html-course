Make the web interactive with TypeScript

TypeScript is JavaScript with a safety net: it spots mistakes while you type, before your program even runs. Every lesson shows the explanation, the code, the errors and the result side by side. No experience needed.

How every lesson works

You learn by looking and trying. Each idea comes with a small program you can change and run.

1 · read

A short, simple explanation

Plain words and pictures. Every new word is explained the first time you meet it.

2 · run

Code, errors and result together

Type mistakes are underlined in red as you type, with a plain explanation. The output or the web page shows what the code does.

3 · try

Change it, break it, fix it

Small tasks and quizzes help it stick. Reset always brings the code back.
