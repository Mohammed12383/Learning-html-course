Why C++?

C++ is one of the most powerful programming languages in the world. It's used when programs need to be very fast or need to control the computer closely:

games

Big game engines like Unreal Engine are written in C++.

browsers

Chrome, Firefox and Safari are mostly C++.

robots

Robots, cars, drones and Mars rovers run C++.

apps

Photoshop, music software, and parts of Windows and macOS.

C++ asks you to be more careful and precise than Python or TypeScript. In return, you learn how computers really work inside: memory, addresses and types. That knowledge makes you better at every language.

What a compiler does

Computers don't understand C++ directly. They only understand machine code: millions of tiny instructions made of 1s and 0s. A program called a compiler translates your C++ into machine code. Then the computer runs that machine code, very fast.

Why does C++ care so much about types?

Because the compiler decides before the program runs exactly how much memory every variable needs and where it lives. That's one reason C++ is so fast. It's also why a variable's type can never change: an int box is always an int box.

Changing values

The compiler refuses: text can't go in an int box. Change "three" to 2.

A surprise: decimals in an int

Putting a decimal into an int doesn't round it. It just chops off everything after the point. Use double for numbers that need decimals.

const and auto

  • const makes a variable that can never change. Use it for things like const int DAYS_IN_WEEK = 7;.
  • auto lets the compiler work out the type from the value: auto x = 5; is an int, auto y = 2.5; is a double.

Delete the line that changes PI to make it compile.

Naming rules

  • Letters, numbers and _ only. No spaces. Can't start with a number.
  • Case-sensitive: score and Score are different.
  • Can't be a keyword like int or return.
  • Common styles: playerScore (camelCase) or player_score (snake_case). Constants are often ALL_CAPS.

Your turn

  1. Make variables for your name (string), age (int), height in meters (double) and first initial (char). Print a sentence with all of them.
  2. Make int coins = 10;, add 5, double it with coins = coins * 2;, and print it.

Common mistakes

  • Using a variable with no value: int x; cout << x; prints a random leftover number from memory! Always give a starting value.
  • Double quotes for char: a char uses single quotes, 'A'. Text uses double quotes, "A".
  • Forgetting #include <string> when using string.
  • Making the same variable twice: int x = 1; int x = 2; is an error. The second time, just write x = 2;.

int n = 7.8; What is in n?

An int can't hold decimals, so the .8 is chopped off (not rounded).

Remember

  • type name = value; makes a variable. The type never changes.
  • int whole numbers, double decimals, char one character, bool true/false, string text.
  • sizeof(type) shows how many bytes it uses.
  • const can't change. auto lets the compiler pick the type.

The integer division surprise

When you divide an int by an int, C++ gives an int answer, and throws away the decimals:

If at least one side is a double, the answer is a double. To divide two int variables properly, turn one into a double with static_cast<double>(x). This is called a cast.

When integer division is useful

Sharing 17 cookies among 5 friends: 17 / 5 is 3 cookies each, and 17 % 5 is 2 left over. And n % 2 == 0 tells you a number is even.

Boxes have limits

An int is 4 bytes, so it can only hold numbers up to about 2.1 billion. Go past that, and the number "wraps around" to a big negative number. This is called overflow. For bigger numbers, use long long (8 bytes, up to about 9 quintillion):

Common mistakes

  • Integer division by accident: 1 / 2 is 0. Write 1.0 / 2.

Boxes side by side

A copy, or the real thing?

This is a big idea in C++. Normally, a function gets a copy of the value. Changing the copy doesn't change the original. This is called pass by value.

Put & after the type, and the function gets a reference: another name for the same box. Changing it changes the original. This is called pass by reference.

This is the lesson that makes C++ special. Every variable lives somewhere in memory, and every place in memory has an address, like a house number. A pointer is a variable that holds an address. It sounds tricky, but with pictures it's simple.

Every box has an address

Why does this matter?

  • Speed: passing an address is much faster than copying a big object.
  • Sharing: several parts of a program can work on the same thing.
  • Building structures: games and apps link objects together with pointers (a player points at their pet, a list item points at the next one).
  • Understanding computers: other languages use pointers too, they just hide them from you.

In modern C++ you'll use references and smart pointers (lesson 15) most of the time, but they're all built on this idea.

Common mistakes

  • Printing the pointer instead of the value: cout << p shows an address. Use *p for the value.
  • Following a nullptr: crashes the program. Check first.
  • Using a pointer that was never set: int* p; points at a random place. Always start with nullptr or an address.

int x = 5; int* p = &x; *p = 9; What is x?

p points at x, so *p = 9 stores 9 in x's box.

  • nullptr means "points at nothing". Check before following it.
  • Prefer references (int&) when you can. Use pointers when it might be empty.

Classes

A class is a struct with superpowers: it bundles data and the functions that work on it, and it can keep its data private so nobody can break it. Classes are the heart of C++. The "++" in the name was originally about adding them.

  • public and private
  • Constructors

  • const methods

A class bundles data and actions

public and private

private:

Only the class's own code can use these. Usually the data goes here, so it can't be changed by accident.

public:

Anyone can use these. Usually the methods go here: the buttons on the outside of the box.

Try adding mine.coins = 1000000; in main above and press Run. The compiler refuses: coins is private. The only way to change it is through add and spend, which check the rules. This idea is called encapsulation: keep the data safe inside, and offer a few safe buttons outside.

Think of it like this

A class is like a vending machine. The snacks and money are inside (private). You can only use the buttons on the front (public). You can't reach in and take a snack for free.

The only difference between struct and class: in a struct, everything is public unless you say otherwise. In a class, everything is private unless you say otherwise.

virtual

Inheritance

In a game, a Warrior, a Wizard and an Archer are all Characters. They share a name and health, but each attacks differently. Inheritance lets you write the shared parts once, and virtual functions let each kind do its own thing.

  • Base and derived classes
  • protected
  • Calling the parent's constructor
  • virtual and override
  • Abstract classes

A class based on another

Write : public Animal after the class name, and the new class (the derived class) gets everything from Animal (the base class):

Animal: name, introduce()
inherits
Cat: sound() → "Meow"
inherits
Cow: sound() → "Moo"
  • Cat(string n) : Animal(n) {} passes the name up to the parent's constructor.
  • protected is like private, but derived classes can use it too.
  • introduce is written once in Animal, and every animal gets it.

virtual: let each class decide

Notice that introduce() lives in Animal, but it calls the right sound() for each animal. That's because sound is marked virtual: "a derived class may replace this". The replacement is marked override, so the compiler can check that it really matches.

Try deleting the word virtual in the code above and press Run: every animal says "..." because introduce no longer looks for the child's version.

Many kinds in one list

The real power: you can keep different kinds of objects in one list, using pointers to the base class, and each one still behaves in its own way. This is called polymorphism ("many shapes"):

  • vector<Character*> holds pointers (lesson 10) to any kind of Character.
  • c->attack() is a shortcut for (*c).attack(): "follow the pointer, then call the method".
  • virtual int attack() const = 0; is a pure virtual function: Character doesn't say how to attack, so every derived class must. A class like that is called abstract, and you can't make an object of it directly.
  • virtual ~Character() {} is a virtual destructor. Always add one to a base class that has virtual functions. (A destructor runs when an object is destroyed.)

Common mistakes

  • Forgetting virtual in the base class: the child's version won't be used through a base pointer.
  • A typo in an overriding method: override makes the compiler catch it. Always write it.
  • Forgetting to call the parent's constructor when it needs values.

The Standard Library

C++ comes with a huge toolbox called the Standard Library (often called the STL). You've already used string and vector. In this lesson you'll meet more power tools: map, set, and ready-made algorithms for sorting and searching.

  • map: look things up by key
  • set: no duplicates
  • sort and other algorithms
  • Lambdas: tiny functions
  • pair and auto

map: a dictionary

A map stores key → value pairs. You look up a value by its key, like a word in a dictionary. map<string, int> has string keys and int values. It keeps the keys sorted automatically.

  • m[key] = value adds or changes. m[key] reads (and creates the key with 0 if it's missing, which is handy for counting).
  • m.count(key) is 1 if the key exists, 0 if not.
  • for (const auto& [key, value] : m) visits every pair. auto lets the compiler work out the type.

set: every value once

Algorithms: sort, find, count and more

Add #include <algorithm> and you get dozens of ready-made algorithms. They work on a range given by begin() and end(): "from the start to the end of this vector".

max_element gives the position of the biggest item (an iterator), so * gets the value there, a bit like a pointer. find gives end() when it finds nothing.

Lambdas: tiny functions on the spot

A lambda is a small function without a name, written right where you need it. They're perfect for telling sort how to sort:

pair: two values together

A pair holds two values: .first and .second. The items in a map are pairs too.

Random numbers

Games need dice rolls and surprises. Modern C++ has <random>: a generator makes random bits, and a distribution turns them into the kind of number you want, like "a whole number from 1 to 6". The generator needs a starting number called a seed:

Change the seed in the Input box and Run: different rolls. Use the same seed again: the same rolls! That's useful for testing a game. For a different game every time, seed it from a truly random source with mt19937 rng(random_device{}());.

Making objects while the program runs

So far, every variable was created when its line ran and destroyed at the end of its { } block. That memory is called the stack. Sometimes you need an object that lives longer, or you don't know how many you'll need. Then you create it on the heap, a big area of memory you manage yourself.

The old way: new and delete

The danger: if you forget delete, the memory is never given back. That's called a memory leak, and big programs that leak slowly use up all the memory. Deleting twice, or using it after deleting, is even worse.

The modern way: smart pointers

A smart pointer deletes the object for you, automatically, when nothing uses it any more. Use unique_ptr (one owner) from <memory>:

~Monster() is the destructor: it runs when an object is destroyed. The output shows that every monster was cleaned up at the closing }, without a single delete. In modern C++, use make_unique instead of new.

Splitting code into files

Big programs are split into many files. Each class usually gets two:

  • a header file .h: the declaration (what exists: the class, its methods' names and types),
  • a source file .cpp: the definitions (the actual code of each method).
robot-game/
├── main.cpp          ← has int main()
├── Robot.h           ← the Robot class declaration
└── Robot.cpp         ← the Robot methods' code

Your own files are included with quotes: #include "Robot.h". Robot::greet means "the greet method that belongs to Robot". In header files, programmers write std::string instead of using using namespace std;, to avoid name clashes in other files.

Compiling on your computer

On a computer with a compiler installed (see lesson 0), open a terminal in your project folder:

  1. Compile one file: g++ -std=c++20 main.cpp -o game (on a Mac, clang++ works the same). -o game names the program.

  2. Compile several files together: g++ -std=c++20 main.cpp Robot.cpp -o game

  3. Run it: ./game on Mac and Linux, or game.exe on Windows. Now cin really waits for you to type!

  4. Add -Wall to get helpful warnings about code that compiles but looks suspicious. Fix them too.

Bigger projects use a build tool like CMake, or an IDE like Visual Studio or CLion that has a big green Run button.

Why use make_unique instead of new?

A unique_ptr deletes its object automatically when it goes away, so you can't forget.

  • <random>: mt19937 rng(seed); and uniform_int_distribution<int> d(1, 6);, then d(rng).
  • Use make_unique<T>(...) and unique_ptr instead of new/delete.
