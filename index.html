How every lesson works

You learn by looking and trying. Each idea comes with a small piece of code you can change.

1 · read

A short, simple explanation

Plain words and pictures. Every new word is explained the first time you meet it.

2 · see

Code and website side by side

The code is on the left, the website it makes is on the right. Sliders let you change sizes and colors and watch both update.

3 · try

Change it, break it, fix it

Small tasks and quick quizzes help it stick. You can't break anything here: the Reset button brings the code back.
